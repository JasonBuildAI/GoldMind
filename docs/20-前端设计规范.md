# 前端设计规范

> 🌐 **中文** | [English](./en/frontend-design.md)

本文件是 GoldMind 前端**视觉语言与界面文案**的唯一真源。改前端界面之前先读这里；
产品做什么看 `docs/00-产品方向.md`，命令与目录看 `README.md`。

> 状态：本规范随 2.0.2（2026-10-03）**前端整体重写**落地 —— 技术栈从 React 换成
> **Vue 3 + TypeScript + Pinia**，视觉语言从「浅色研究简报」换成 **Apple macOS / HIG**，
> 目录按功能分组。此后新增界面一律先在这里补规则，再去写代码。

---

## 一、气质

GoldMind 的界面是一份**财经研究简报**，观感上像 macOS 上的一个原生应用，不是一块 AI 展示板：

- 读起来像研报：先结论、后论据；数字可核对，来源可追溯。
- 安静：没有装饰性渐变、没有发光、没有玻璃拟态堆叠、没有彩色徽章与感叹式文案。
- 分层：层级由**表面、发丝线、圆角与极轻阴影**建立（macOS 的做法），而不是靠卡片套卡片。

**唯一的「用力处」是左栏的当日报价块与各节的「一行结论」**。其余一切保持克制。

## 二、设计令牌

定义在 `app/src/styles/tokens.css`，组件只允许引用令牌，**不允许写新的十六进制颜色**
（`app/src/__tests__/guards/designTokens.test.ts` 会在闸门里守住这一条）。
`app/src/lib/tokens.ts` 保留一份运行时兜底值供 SVG 使用，两边由
`lib/__tests__/tokens.test.ts` 比对，漂开即红。

### 表面与线

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#F2F2F7` | 窗口底 |
| `--surface` | `#FFFFFF` | 内容面：卡片、表格、面板 |
| `--surface-2` | `#FBFBFD` | 次级面：表头、页脚、条带 |
| `--surface-sunken` | `#ECECF0` | 凹陷面：分段控件轨道 |
| `--fill-quaternary` | `rgba(120,120,128,.08)` | 悬停 / 选中底 |
| `--separator` | `#D8D8DE` | 发丝线（1px 分隔线、表格线、网格线） |

### 文字与语义色

| 令牌 | 值 | 白底对比度 | 用途 |
|---|---|---|---|
| `--text` | `#1D1D1F` | 16.7:1 | 标题与正文 |
| `--text-secondary` | `#6E6E73` | 5.1:1 | 次要信息（时间、来源、说明） |
| `--text-tertiary` | `#6E6E73` | 5.1:1 | 与 secondary 同值 —— 更浅的灰（Apple `#8E8E93`）只有 3.3:1，不到 4.5:1；层次改由字重与字号表达 |
| `--accent` | `#0071E3` | 4.6:1 | Apple 蓝：链接、选中 tab、主按钮 |
| `--gold` | `#A67C00` | 4.5:1 | 金价与关键数字的**唯一**强调色 |
| `--up` | `#C8102E` | 6.2:1 | 上涨（红） |
| `--down` | `#1D7A3E` | 5.4:1 | 下跌（绿） |
| `--warn` | `#8A5300` | 6.3:1 | 需要留意 |
| `--danger` | `#B3261E` | 6.6:1 | 失败、缺口年 |

语义色规则：

- 涨跌方向**必须同时**由 ▲▼ 与「涨/跌」文字表达，颜色只是加强，不单独承载语义。
- 红涨绿跌，符合中文投资者的阅读习惯。
- 所有前景/背景对按 **4.5:1** 实测；改色时同步更新上表的对比度列。
- 「积累期」是中性事实（新序列样本尚短），用普通标签样式表达，**不得**用错误 / 缺口色；
  「缺口年」才是异常，按错误样式标注。

### 几何与阴影

| 令牌 | 值 | 用途 |
|---|---|---|
| `--radius-sm` | `6px` | 按钮、输入、标签 |
| `--radius` | `8px` | 卡片、面板、表格容器 |
| `--radius-lg` | `10px` | 侧边栏、sheet |
| `--radius-pill` | `999px` | 药丸标签、导航项 |
| `--shadow-1` | `0 1px 2px rgba(0,0,0,.04), 0 1px 1px rgba(0,0,0,.03)` | 卡片、表格容器 |
| `--shadow-2` | `0 8px 24px rgba(0,0,0,.08), 0 1px 2px rgba(0,0,0,.04)` | 浮层：提示卡、跳转链接 |

**阴影只有两级，同级不混用。** 硬约束：**禁止装饰性渐变、发光、彩色徽章与 `filter: blur`
的堆叠**；左侧栏、卡片浮层与提示卡的 `backdrop-filter` 是唯一允许的模糊（见第四节）。

### 字体与版式

- 全走系统栈：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`。
  零下载、零新增资产。**没有衬线栈** —— 标题与正文同族，靠字重 / 字号 / 字距分层。
- 全部数字使用 `font-variant-numeric: tabular-nums`；价格与涨跌幅右对齐。
- 字号（Apple 阶梯）：11 / 12 / 13 / 15 / 17 / 20 / 22 / 28 / 34 / 40。
- 正文行高 1.6，标题行高 1.25；正文行宽 ≤ 68ch；段落左对齐，不居中正文。
- 日期与时间只展示后端返回的字段，不自行推算「今天」（见 `docs/ARCHITECTURE.md` 第七节）。
- **数字进表格**：同一实体的多个数值（统计、因子、监测、回测、来源状态）必须排版成表，
  不用逗号串成一句话；只有「一行结论」允许把两三个关键数字写进句子。

## 三、目录与组件

前端是 **Vue 3 单文件组件 + Pinia**，两个 HTML 入口（`index.html` 看板、`research.html` 研究页），
**没有客户端路由** —— 相对链接 `./research.html` 直接跳。

```
app/src/
├── styles/{tokens.css,base.css}    设计令牌 + 基础样式与语义类（唯一真源）
├── testids.ts                      选择器契约（见第七节）
├── entries/{dashboard,research}.ts 两个入口：装 Pinia、引样式、挂载
├── services/api.ts                 HTTP 客户端与响应类型
├── stores/{market,freshness,aiConfig}.ts   Pinia store
├── composables/{useAsyncBlock,useFreshnessBlock}.ts
├── lib/{format,placeholder,apiError,tokens}.ts
├── components/                     通用件（含 charts/）
├── layout/{AppSidebar,FooterBar}.vue  左侧栏与页脚
├── views/dashboard/                看板八节 + quant/ 与 data/ 子件
└── views/research/                 研究页八节
```

### 通用组件

| 组件 | 职责 | 约束 |
|---|---|---|
| `AppSidebar` | 左侧栏：字标、导航、（看板才有的）今日速览与数据新鲜度 | `variant` 决定看板 / 研究页；整列吸顶（`pageStructure.test.ts` 要求全页只有一个 `<nav>`，所以两个入口共用它）；**研究页必须带返回按钮**，字标在两边都是回主页的链接 |
| `SectionBlock` | 节容器：锚点、标题、一句话说明、操作区 | 标题左对齐；`verdict` 插槽放「一行结论」 |
| `PanelBlock` | 卡片 / 面板：标题 + 右上角元信息 | 同级只用 `--shadow-1`；嵌套时用 `plain` 去阴影 |
| `DataTable` | 通用数据表：列定义、行键、空态、固定来源列 | 窄屏横向滚动；单元格内容优先取同名具名插槽 |
| `TabsNav` | 分段控件 + ARIA tablist | **`panelId` 必填**：同页多组标签时 id 不能撞车 |
| `Disclosure` | 一层折叠（原生 `<details>`） | **禁止嵌套两层** |
| `StateBlock` | 加载 / 正在分析 / 不可用三态 | `role="status"`；不可用时必须给出原因与下一步 |
| `RefreshButton` | 手动触发分析或抓取 | 文案「重新分析」/「重新抓取」/「抓取最新消息」，进行中文案随动作；禁用态可见 |
| `QuoteBlock` | 报价：名称、数值、涨跌、来源 | 数值用等宽数字；涨跌同时有 ▲▼ 与文字 |
| `MetadataBlock` | 生成信息（缓存 / 来源 / 方法 / 时间） | 只展示后端字段，不推算 |
| `FactorList` | 因子条目，每条一个折叠 | 原生 `<details>`，键盘可用 |
| `InstitutionTable` | 机构观点表 | 含预测日期与滞后标注；窄屏横向滚动 |
| `StrategyColumns` | 三档策略对照 | 窄屏堆叠为单栏 |
| `charts/{AreaChart,DualAxisLineChart}` | 自绘 SVG 图表 | 末点不闪烁、无入场动画、无渐变；悬停提示只在鼠标进入时出现；**必须清掉 `figure` 的默认外边距**（1em 40px，否则窄屏顶出容器） |
| `SignOff` | 分析署名行 | 模型名从 `/health` 读，读不到写「模型未知」 |

### 版式原语（`styles/base.css`）

| 原语 | 用途 | 关键约束 |
|---|---|---|
| `.app-shell` | 两栏壳：`左栏 + minmax(0, 1fr)` | 宽屏铺满；`> 960px` 一栏 |
| `.app-shell__content` | 右列容器（内容 + 页脚同宽） | `min-width: 0`，否则表格把整页顶宽 |
| `.app-main` | 内容区 | `min-width: 0`；四周留 `--shell-gap` / `--shell-pad` |
| `.wrap` / `.wrap--fill` | 版心；`--fill` 变体跟着内容区铺满 | 单列场景才用 `.wrap` |
| 栅格子项 `min-width: 0` | `.app-shell`/`.grid-2`/`.grid-3`/`.stack`/`.metrics` 的子项 | **必须加**：默认 `min-width: auto` 会让长段落、表格、图表把轨道顶宽，表现为整页横向滚动 |
| `.table-scroll` | 表格横向滚动容器 | 自身也要 `min-width: 0; max-width: 100%`，否则「表格内滚动」变成「整页滚动」 |

### 数据流

```
区块组件 ──useAsyncBlock──► services/api.ts ──► 后端
   │                              ▲
   └─useFreshnessBlock──► stores/freshness ──► 左栏的数据新鲜度
行情轮询 ──stores/market（30 秒，页面隐藏暂停）──► 行情 / 驱动区块
```

- `useAsyncBlock(fetcher, {fallback, timeout})`：首次加载与「重新分析」分开计状态，
  失败统一经 `describeApiError` 翻译成人话。**超时必须单独给文案** —— 分析接口要跑一次 LLM，
  「稍后重试」与「取不到结果」的处置不同。
- `stores/market`：行情数据的唯一来源，30 秒轮询（页面隐藏时暂停、切回立即补一次），
  5 秒缓存窗口，同 URL 在飞去重。
- 区块**不直接渲染新鲜度**：登记到 `stores/freshness`，左栏统一展示（同一事实只有一个来源）。

## 四、版式与阅读顺序

**整页是两栏壳（`.app-shell`）：左侧栏 + 内容区。**

```
┌───────────────────┬──────────────────────────────────────────────┐
│ 左侧栏 .toolbar   │ 内容区 .app-main（吃掉剩余宽度，整页铺满）    │
│  · 字标           │                                              │
│  · 锚点导航       │  今日结论 → 行情 → 驱动 → 消息                │
│  · 今日速览       │  → 量化预测 → 投资策略 → 数据与方法            │
│  · 数据新鲜度     │                                              │
│  （整列吸顶）     │  页脚 .footer（同宽，也铺满）                  │
└───────────────────┴──────────────────────────────────────────────┘
```

- 左栏固定 `--sidebar-width`（300px），**整列 `position: sticky`**、可独立滚动；
  底色比内容面深一档（`--sidebar-bg`），右侧一条发丝线。
- **返回入口**：研究页是独立入口（`research.html`），没有客户端路由 —— 回看板只能靠普通链接。
  因此研究页左栏最上面有一个显式的**返回按钮**（`a.toolbar__back`，「‹ 返回看板」，
  指向 `./index.html`），两个入口的**字标本身也是回主页的链接**（macOS 的标准做法）。
  返回这件事值得有两个入口：只把「看板」当成导航里的一项，用户会找不到路
  （`ResearchPage.test.ts` 守着这条）。
- 内容区 `grid-template-columns: minmax(0, 1fr)`，把剩余宽度全部吃掉 ——
  不再把正文居中收窄到 1180px。**可读性靠各区块自己的 `--measure`（68ch）行宽上限
  保证**，而不是靠把整页压窄；表格与图表因此能在宽屏上一次看全。
- `--shell-max`（2400px）只在超宽屏上兜底，避免 4K 上正文被拉成一行 200 字符。
- **窄于 `--bp-narrow`（960px）落成单栏**：左栏回到页面顶部横条（导航转横排、
  新鲜度改成多列网格），内容区独占整行。断点写在 media query 里（CSS 变量不能用在
  媒体查询条件中），`base.css` 里的 960px 必须与 `tokens.css` 的 `--bp-narrow` 保持一致。
- 左栏的类名仍叫 `.toolbar`（`scripts/capture_screenshots.mjs` 与
  `scripts/verify_layout.mjs` 按它定位），但它是**栏**不是条。

**看板（`app/src/views/dashboard/DashboardPage.vue`）自上而下只有一个入口，顺序固定**：

1. 左侧栏 `AppSidebar`（`variant="dashboard"`）：字标 + 锚点导航（今日结论 / 行情 / 驱动 /
   消息 / 量化预测 / 投资策略 / 数据与方法 / 研究）+ 今日速览 + 数据新鲜度
2. 今日结论 `#conclusion`
3. 行情 `#market`
4. 驱动 `#drivers`（看涨 `#drivers-bullish` / 看跌 `#drivers-bearish` / 机构 `#institutions`）——
   模型对当天事实的解读
5. 消息 `#messages`（2026-10-03 起的一等板块：高权威原始消息，三个窗口各取前 10 条。
   此前挂在「驱动」里，侧边栏连入口都没有 —— 原始事实与对它的解读分成两节，各自可达）
6. 量化预测 `#quant`（决策尺度 → 公允价值分解 → 监测信号 → 回测评估 → 四类影响因素）
7. 投资策略 `#strategy`
8. 数据与方法 `#data-methods`（同步报告 → 数据源可用性 → 初始化进度 → 配置与热加载 →
   服务状态 → 口径说明与图例）
9. 页脚 `FooterBar`（数据来源 / 分析模型 / 统一免责声明）

**研究页（`app/src/views/research/ResearchPage.vue`）顺序固定**：
左栏 `AppSidebar`（`variant="research"`，多一个回看板的链接与报告生成时间）→
版本与裁决 `#verdict` → 前向留出期 `#forward`（含 Beta 后验与 CRPS）→ 覆盖度 `#coverage`
→ 校准诊断 `#diagnostics` → 分段与 Regime 候选 `#regimes` → 因子拆解 `#factors`
→ 基准候选 `#benchmarks` → 同步报告 `#sync`。

**左栏的观感**：半透明底 + `backdrop-filter: saturate(180%) blur(20px)`；
`@supports not (backdrop-filter: …)` 时退回不透明 `--sidebar-bg`。
今日速览在左栏里竖排：主数字用 `--text-2xl` 加粗、染 `--gold`，涨跌另起一行给
「▲ + 百分比 + 涨/跌」，口径与来源收在小字 meta 行。

**可读性硬规则**（每一节都必须满足）：

- 每节第一行是「一行结论 + 关键数字」，细节一律收进**至多一层**折叠；
  不允许嵌套两层折叠（`pageStructure.test.ts` 会守住）。
- 有来源 / 数据截至的数据，表格里必须有固定的「来源」「数据截至」列，逐行给值，
  不让读者回头猜；缺值写「—」，不省略列。
- 每个字段都必须有展示位；宁可显示「—」或降级说明，也不隐藏字段（见第八节）。
- 颜色只做加强，语义必须由 ▲▼ 或文字承担。
- 顺序即优先级：把最重要的结论放在最上面，不必让读者先读方法再读结论。

**数据新鲜度**：左栏里逐块**竖排**列出 `行情 / 美元指数 / 看涨因素 / 看跌因素 / 消息 /
机构观点 / 量化预测 / 投资策略 / 今日结论` 的数据截至或分析时间与状态
（fresh / analyzing / stale / unavailable / pending），并给出顶层状态汇总。
没有时间的块显示「时间未知」，不拿浏览器时钟顶替。

**版式自检**：`cd app && node scripts/verify_layout.mjs`（需要真实栈在跑）。
单元测试跑在 happy-dom 里、**没有排版引擎**，「整页横向滚动」这类问题它看不见 ——
该脚本在真实浏览器里实测 1440×900 与 390×844 两档：无横向溢出（越界元素点名）、
两栏铺满与窄屏单栏、左栏吸顶与发丝线、令牌生效、无装饰性渐变/发光、锚点可达、
正文与次要文字对比度 ≥ 4.5:1。

## 五、区块口径

**量化预测页（`QuantSection`）的区块顺序**（自上而下）：

1. 结论行 —— 模型版本、因子可用数、数据截至与一年尺度的一句话结论；
2. **决策尺度** —— 五个尺度 tab（1 日 / 1 周 / 1 月 / 1 季 / 1 年）：方向（校准后的期望收益漂移，
   恰为 0 记「持平」）、上行概率、基准价与目标价、三情景区间与触发 / 失效条件、逐因子贡献；
   250 日方向允许 `not_published`，页面显示 `direction_reason` 的原文，**不得**画假箭头；
3. **公允价值分解** —— 市场价 vs 公允价、四块构成与驱动、拟合 R² 与样本数；
4. **监测信号（周更表）** —— 参与信号与「只看不评」分组：
   - **参与信号**：进合成得分、带方向（多 / 空 / 中性）；
   - **只看不评**：信息型指标（USDCNY、人民币金价、CFTC 未平仓、GVZ、金银比、铜金比、
     持仓比、GPR、消息强度等）只给数值与规则说明，不下方向判断。
5. **回测评估** —— 本模型与基准并排（永远看多 / 动量 / 抛硬币），CRPS 分数与技能、
   Beta 后验、分段走查（含每段的命中率、两个基准与原因）；样本不足写原因；
6. **四类影响因素** —— 逐因子表（含覆盖画像与发布滞后）。

量化页特有的口径：同步报告里的「未到期」等逐源状态收在折叠的「数据源状态」区，不占主版面；
任何一块不可用都只给原因，不摆数字；多空信号只能来自后端
`backend/app/services/quant/monitor.py` 里的确定性规则，界面不自己下判断。
情景的触发 / 失效条件必须能回到因子表与 200 日均线核对，界面不另算一套数字。
基准的可选性与滚动说明（roll / rollover note）必须原样展示，不美化。

**消息板块（`MessagesPanel`）的口径**：三个窗口各自取前 10 条，同一事件可以同时出现在多个窗口；
展开区给出摘要、评分依据（signals）、事件标注（event_tags）与同题报道链接；
经聚合入口的链接标注「经聚合入口」（`via_aggregator`）；顶部元信息展示上次抓取时间，
手动抓取后追加本次抓取报告（成功源数 / 新增条数 / 失败源数 / 译出中文条数）。空窗口与空库分开：
空窗口一句说明，空库按 `StateBlock` 给出后端原因与重试路径。

**消息中文化的展示口径（2026-10-03）**：来源全是英文，每条消息在**折叠态**就给出中文标题与
2–3 句中文导语 —— 读者不必逐条展开才知道「今天发生了什么」。

- **中文是叠加，不是替换**：英文原题始终可见（中文标题下面那行小字），英文摘要原文留在展开区，
  AI 产出带「AI 译」标记与一句来源说明（模型名 + 生成时间 + 口径）。读者能逐条核对，而不是只能相信。
- **翻译状态单独一行**：开关状态 / 模型 / 待翻译条数 / 原因。原因只在「确实还有待翻译条目、
  而当前翻不了」时才有值（关掉了 / LLM 未配置 / 当日预算用尽 / 上次解析失败），
  全都翻好了就不摆一句「暂不可用」吓人。
- **没有中文时不凑**：显示英文标题 + 「中文翻译暂不可用（原因）」；不许用词典、模板或模型印象
  拼一段中文顶上（`AGENTS.md` 红线 1）。前端不补译、不重排、不参与评分。
- **禁用词照旧**：不得把翻译说成「实时翻译」「精准翻译」这类能力宣称（见第六节）。

**金价的刷新时间（2026-10-03）**：页面上有六处展示国际金价 —— 侧边栏今日速览、行情节与
报价块、今日结论「当前价格」、投资策略降级快照、量化预测「基准价」、公允价值「市场价」。
**每一处都必须同时给出该价格自己的 as-of、口径与来源**：

- 时间取**这个价格自己的**字段（`stats.price_as_of` / `summary.price_as_of` /
  `advice.snapshot.as_of` / `predictions.as_of` / `fair_value.as_of`），不用浏览器时钟、
  不用页面加载时间顶替（红线：时间只走后端字段）。
- 缺 as-of 时如实写「金价刷新时间未知（后端未返回）」—— 编一个「刚刚」比不给时间更糟。
- 措辞、缺失时的说法与字段级选择器只在一个组件里定：`components/GoldPriceAsOf.vue`，
  六处引用同一份实现（同一事实只有一个来源，措辞不会各漂各的）。
- 机构目标价与模型预测价**不是**当前金价，不套这条规则（它们的日期在各自的表里）。

**研究页的口径**：裁决只认前向留出期的独立下注，没攒够时状态写「尚不可判」并给出
还差多少个交易日，**不许**写成「未过线」；历史留出期那一列必须标注「已被看过，只作记录」；
数据窗口（起止 + 交易日数 + 年数）在页头显著标注。

## 七、测试选择器契约（TESTIDS）

唯一真源是 `app/src/testids.ts`，导出 `Object.freeze` 的 `TESTIDS`：

- **结构选择器**（`TESTIDS.app` / `sectionQuant` / `quantFairValue` / `researchVerdict` …）：

- **字段选择器**：`fieldTestId(path)` = `` `field-${path}` ``，路径用「响应类型.字段名」

  `accuracy.regimes.pre.accuracy`）。嵌套组件（`research`、`health`）在 `TESTIDS.field`

  `app/scripts/capture_screenshots.mjs` 是 `.mjs`、不能 import TS，使用同名字面量，

- **禁止**在测试里手写 `field-` 字符串或裸 `data-testid` 值；必须经 `TESTIDS` /
  `fieldTestId()` 引用。

**闸门里的守卫**（`app/src/__tests__/guards/` 与各区块 `__tests__/`）：

## 九、动效、无障碍与打印

- 动效只用于回应人的操作（如刷新中、悬停、展开），不做自动播放入场动画；
  `prefers-reduced-motion` 下全部关闭。时长令牌：`--dur-fast` 150ms、`--dur` 220ms。
- 语义标签：`header` / `nav` / `main` / `footer`；每页一个 h1；skip link 直达主内容。
- 键盘焦点可见（`box-shadow: 0 0 0 3px rgba(0,113,227,.35)`）；交互元素必须是
  `<button>` / `<a>` / `<details>` 等原生元素，禁止 `div[onclick]`。
- tablist 用 ARIA 规范行为：← → 在标签间移动（自动激活），Home / End 跳到首尾，
  只有当前标签在 Tab 序列里（roving tabindex）；`id` / `aria-controls` 带实例前缀。
- 打印：隐藏导航与操作按钮、去底色、表格与图表块内避免断页。
