# 前端设计规范

> 🌐 **中文** | [English](./en/frontend-design.md)

本文件是 GoldMind 前端**视觉语言与界面文案**的唯一真源。改前端界面之前先读这里；
产品做什么看 `docs/00-产品方向.md`，命令与目录看 `README.md`。

> 状态：本规范随 2026-09-30 的前端表现层重构落地。此后新增界面一律先在这里补规则，再去写代码。

---

## 一、气质

GoldMind 的界面是一份**财经研究简报**，不是一块 AI 展示板：

- 读起来像研报：先结论、后论据；数字可核对，来源可追溯。
- 安静：没有渐变、没有发光、没有玻璃拟态、没有装饰性图标与感叹式文案。
- 结构化：层级由细线、留白与字号建立，而不是靠卡片、阴影和彩色徽章。

**唯一的「用力处」是报头的当日报价块**（大号衬线数字 + 涨跌 + 数据来源与时间）。
其余一切保持克制。

---

## 二、设计令牌

定义在 `app/src/styles/tokens.css`，组件只允许引用令牌，不允许写新的十六进制颜色。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#F6F6F3` | 页面底色 |
| `--surface` | `#FFFFFF` | 表格、面板底色 |
| `--ink` | `#17191B` | 标题与正文 |
| `--ink-muted` | `#5C6166` | 次要信息（时间、来源、说明） |
| `--rule` | `#D9DAD4` | 1px 分隔线、表格线、网格线 |
| `--gold` | `#8A6A12` | 金价与关键数字的唯一强调色（白底对比度 ≈5.1:1） |
| `--up` | `#B4232A` | 上涨（红） |
| `--down` | `#16653C` | 下跌（绿） |

语义色规则：

- 涨跌方向**必须同时**由 ▲▼ 与「涨/跌」文字表达，颜色只是加强，不单独承载语义。
- 红涨绿跌，符合中文投资者的阅读习惯。

硬约束：无渐变、无阴影、无模糊；圆角 0–2px；禁止 `backdrop-filter`。

## 三、字体与排版

- 标题与数字：`Georgia, "Songti SC", "Noto Serif CJK SC", SimSun, serif`
- 正文与界面：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", Arial, sans-serif`
- 全部数字使用 `font-variant-numeric: tabular-nums`；价格与涨跌幅右对齐。
- 字号：12 / 13 / 15 / 17 / 20 / 26 / 34；正文行高 1.75，标题行高 1.25。
- 正文行宽 ≤ 68ch；段落左对齐，不居中正文。
- 日期与时间只展示后端返回的字段，不自行推算「今天」（见 `docs/ARCHITECTURE.md` 第七节）。

---

## 四、版式

- 页面结构：报头（字标 + 锚点导航 + 数据来源与时间）→ 七节（行情 / 多空对照 / 机构观点 /
  消息 / 投资策略 / 量化预测 / 总结）→ 页脚（数据来源、模型说明、免责声明）。
- 最大宽度 1180px，全部左对齐；节与节之间用一条 `--rule` 细线分隔。
- 每节一个 h2，节内每个面板一个 h3；不使用 01/02/03 之类的编号装饰。
- 窄屏：多栏降为单栏，表格在容器内横向滚动；最小支持 360px 宽。

## 五、组件

| 组件 | 职责 | 约束 |
|---|---|---|
| `Section` | 节容器：锚点、标题、一句话说明、操作区 | 标题左对齐，上缘一条细线 |
| `StateBlock` | 加载 / 正在分析 / 不可用三态 | `role="status"`；不可用时必须给出原因与下一步 |
| `RefreshButton` | 手动触发分析或抓取 | 文案「重新分析」/「重新抓取」/「抓取最新消息」，进行中文案随动作（「分析中…」/「抓取中…」）；禁用态可见 |
| `Quote` | 报价：名称、数值、涨跌、来源 | 数值用衬线数字；涨跌同时有 ▲▼ 与文字 |
| `FactorList` | 因子条目，可展开要点 | 用原生 `<details>`，键盘可用 |
| `InstitutionTable` | 机构观点表 | 窄屏横向滚动，表头不随滚动丢失 |
| `Messages` | 消息板块：24 小时 / 7 天 / 30 天三个窗口 tab，每条可展开 | 分数与排序全部来自后端确定性评分，前端不重排、不补算；窗口重叠是设计行为；原文链接新窗口打开（`target="_blank"` + `rel="noreferrer noopener"`）；抓不到只显示「不可用 + 原因」，不摆任何内置消息 |
| `StrategyColumns` | 三档策略对照 | 窄屏堆叠为单栏 |
| `Quant` | 量化预测：结论 / 公允价分解 / 监测仪表盘 / 回测命中率 / 四类因子表 | 每个因子必须显示数据截至与来源；不可用要给原因，算不出的字段显示「—」，不填默认值 |

**量化预测页（`Quant`）的区块顺序**（自上而下，2026-10-01 起）：

1. 预测结论 —— 五个尺度 tab（1 日 / 1 周 / 1 月 / 1 季 / 1 年），每个尺度给方向（校准后的期望收益
   漂移，恰为 0 记「持平」）、上行概率、基准价与目标价、三情景区间与触发 / 失效条件、逐因子贡献，
   并单列一行「因子偏向（未校准）」＝ 合成得分，只作对照；
2. 公允价值分解 —— 市场价 vs 公允价、四块构成（宏观锚 / 需求结构 / 风险溢价 / 情绪残差）与拟合 R²；
3. 监测仪表盘（周更表）—— 每行给指标、频率、来源、最新值、变化、数据截至、信号与规则说明；
4. 回测命中率 —— 本模型（校准后的漂移方向）与三个基准并排，未校准的因子偏向单列一行，
   附 80% 名义区间的实际覆盖率与 2022 年前后分段；
5. 四类影响因素 —— 逐因子表。

量化页特有的口径：任何一块不可用都只给原因，不摆数字；多空信号只能来自后端
`backend/app/services/quant/monitor.py` 里的确定性规则，界面不自己下判断；
信息型指标（USDCNY、人民币金价、COMEX 未平仓量）只给数值，不给方向。
情景的触发 / 失效条件必须能回到因子表与 200 日均线核对，界面不另算一套数字。

消息板块（`Messages`）的口径：三个窗口各自取前 10 条，同一事件可以同时出现在多个窗口；
展开区给出摘要、评分依据（signals）与同题报道链接；顶部元信息展示上次抓取时间，
手动抓取后追加本次抓取报告（成功源数 / 新增条数 / 失败源数）。空窗口与空库分开：
空窗口一句说明，空库按 `StateBlock` 给出后端原因与重试路径。

## 六、界面文案

**禁用词**（界面上一律不出现）：

`Agent`、`多 Agent`、`智能驱动`、`ReAct`、`RAG`、`深度学习`、`实时抓取`（作为能力宣称），
以及 Sparkles / Bot / Brain 一类「AI 装饰」图标与 🚀✨🤖 等表情符号。

理由：当前实现是单轮 LLM 调用（见 `docs/00-产品方向.md` 第三节），这些词要么不实，要么只是装饰。

**术语表**（界面统一用词）：

| 场景 | 用词 |
|---|---|
| 分析结果的两个方向 | 看涨因素 / 看跌因素 |
| 机构目标价区块 | 机构观点 |
| 策略区块 | 投资策略 |
| 结论区块 | 市场总结 |
| 数据取不到 | 数据不可用（并说明原因） |
| 后端已开始分析 | 正在分析（并说明这是占位内容） |
| 分析生成时间 | 分析时间 |
| 行情来源 | 数据来源 |

**署名行**：每个分析区块底部标注
`由 {provider} {model} 生成 · 分析时间 {generated_at} · 仅供参考`；
读不到模型名时写「模型未知（/health 未返回）」，不硬编码型号。

**页脚**：数据来源一栏只列真实来源（腾讯财经、新浪财经、RSS 新闻源），
模型一栏照上面的署名行规则展示，并注明
「机构观点取每家机构最近一次可核实的预测，可能滞后（表内标注预测日期）」；免责声明保留。

**底线**：不编造数据。数据源不可用时宁可显示「数据不可用」，不得用内置常量、默认值或
模型印象生成机构目标价、央行购金量、金价点位等具体数字（见 `docs/00-产品方向.md` 第五节）。

## 七、动效、无障碍与打印

- 动效只用于回应人的操作（如刷新中），不做自动播放入场动画；`prefers-reduced-motion` 下全部关闭。
- 语义标签：`header` / `nav` / `main` / `footer`；每页一个 h1；skip link 直达主内容。
- 键盘焦点可见（2px ink 外框）；交互元素必须是 `<button>` / `<a>` / `<details>` 等原生元素。
- 打印：隐藏导航与操作按钮、去底色、表格与图表块内避免断页。
