# 前端设计规范

> 🌐 **中文** | [English](./en/frontend-design.md)

本文件是 GoldMind 前端**视觉语言与界面文案**的唯一真源。改前端界面之前先读这里；
产品做什么看 `docs/00-产品方向.md`，命令与目录看 `README.md`。

> 状态：本规范随 2.0.2（2026-10-03）前端表现层重写落地：看板改为自上而下的单一阅读顺序、
> 每节一行结论 + 关键数字、全字段展示位与测试选择器契约。此后新增界面一律先在这里补规则，
> 再去写代码。

---

## 一、气质

GoldMind 的界面是一份**财经研究简报**，不是一块 AI 展示板：

- 读起来像研报：先结论、后论据；数字可核对，来源可追溯。
- 安静：没有渐变、没有发光、没有玻璃拟态、没有装饰性图标与感叹式文案。
- 结构化：层级由细线、留白与字号建立，而不是靠卡片、阴影和彩色徽章。

**唯一的「用力处」是报头的当日报价块**（大号衬线数字 + 涨跌 + 数据来源与时间）。
其余一切保持克制。

## 二、设计令牌

定义在 `app/src/styles/tokens.css`，组件只允许引用令牌，不允许写新的十六进制颜色。

| 令牌 | 值 | 用途 |
|---|---|---|
| `--paper` | `#F6F6F3` | 页面底色 |
| `--surface` | `#FFFFFF` | 表格、面板底色 |
| `--ink` | `#17191B` | 标题与正文 |
| `--ink-muted` | `#5C6166` | 次要信息（时间、来源、说明） |
| `--rule` | `#D9DAD4` | 1px 分隔线、表格线、网格线 |
| `--gold` | `#8A6A12` | 金价与关键数字的唯一强调色（白底对比度 ≈5.1:1） |
| `--up` | `#B4232A` | 上涨（红） |
| `--down` | `#16653C` | 下跌（绿） |

语义色规则：

- 涨跌方向**必须同时**由 ▲▼ 与「涨/跌」文字表达，颜色只是加强，不单独承载语义。
- 红涨绿跌，符合中文投资者的阅读习惯。
- 「积累期」是中性事实（新序列样本尚短），用普通标签样式表达，**不得**用错误 / 缺口色；
  「缺口年」才是异常，按错误样式标注。

硬约束：无渐变、无阴影、无模糊；圆角 0–2px；禁止 `backdrop-filter`。

## 三、字体与排版

- 标题与数字：`Georgia, "Songti SC", "Noto Serif CJK SC", SimSun, serif`
- 正文与界面：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", Arial, sans-serif`
- 全部数字使用 `font-variant-numeric: tabular-nums`；价格与涨跌幅右对齐。
- 字号：12 / 13 / 15 / 17 / 20 / 26 / 34；正文行高 1.75，标题行高 1.25。
- 正文行宽 ≤ 68ch；段落左对齐，不居中正文。
- 日期与时间只展示后端返回的字段，不自行推算「今天」（见 `docs/ARCHITECTURE.md` 第七节）。
- **数字进表格**：同一实体的多个数值（统计、因子、监测、回测、来源状态）必须用
  `DataTable` 排版成表，不用逗号串成一句话；只有「一行结论」允许把两三个关键数字写进句子。

## 四、版式与阅读顺序

**看板（`app/src/App.tsx`）自上而下只有一个入口，顺序固定**：

1. 报头 `Masthead`：字标 + 锚点导航（今日结论 / 行情 / 驱动 / 量化预测 / 投资策略 /
   数据与方法 / 研究）+ 今日速览 + 数据新鲜度条
2. 今日结论 `#conclusion`
3. 行情 `#market`
4. 驱动 `#drivers`（看涨 `#bullish` / 看跌 `#bearish` / 消息 `#messages` / 机构 `#institutions`）
5. 量化预测 `#quant`（决策尺度 → 公允价值分解 → 监测信号 → 回测评估 → 四类影响因素）
6. 投资策略 `#strategy`
7. 数据与方法 `#data-methods`（数据源可用性 / 初始化进度 / 同步报告 / 配置与热加载 / 服务状态 / 口径说明与图例）
8. 页脚 `Footer`（数据来源 / 分析模型 / 统一免责声明）

**研究页（`app/src/research/ResearchPage.tsx`）**顺序固定：
版本与裁决 `#verdict` → 前向留出期 `#forward` → 覆盖度 `#coverage` → 诊断 `#diagnostics`
→ 分段 `#regimes` → 因子拆解 `#factors` → 基准候选 `#benchmarks` → 同步报告 `#sync`。

**可读性硬规则**（每一节都必须满足）：

- 每节第一行是「一行结论 + 关键数字」，细节一律收进**至多一层** `<details>`；
  不允许嵌套两层折叠。
- 有来源 / 数据截至的数据，表格里必须有固定的「来源」「数据截至」列，逐行给值，
  不让读者回头猜；缺值写「—」，不省略列。
- 每个字段都必须有展示位；宁可显示「—」或降级说明，也不隐藏字段（见第九节）。
- 颜色只做加强，语义必须由 ▲▼ 或文字承担。
- 顺序即优先级：把最重要的结论放在最上面，不必让读者先读方法再读结论。

**数据新鲜度条**（`FreshnessContext`）：报头里逐块列出 `行情 / 美元指数 / 看涨因素 / 看跌因素 /
消息 / 机构观点 / 量化预测 / 投资策略 / 今日结论` 的数据截至或分析时间与状态
（fresh / analyzing / stale / unavailable / pending），并给出顶层状态汇总。
没有时间的块显示「时间未知」，不拿浏览器时钟顶替。

## 五、组件

| 组件 | 职责 | 约束 |
|---|---|---|
| `Section` | 节容器：锚点、标题、一句话说明、操作区 | 标题左对齐，上缘一条细线 |
| `DataTable` | 通用数据表：列定义、行键、空态、固定来源列 | 窄屏横向滚动；表头不随滚动丢失 |
| `MetadataBlock` | 生成信息（缓存 / 来源 / 方法 / 时间） | 只展示后端字段，不推算 |
| `StateBlock` | 加载 / 正在分析 / 不可用三态 | `role="status"`；不可用时必须给出原因与下一步 |
| `RefreshButton` | 手动触发分析或抓取 | 文案「重新分析」/「重新抓取」/「抓取最新消息」，进行中文案随动作；禁用态可见 |
| `Quote` | 报价：名称、数值、涨跌、来源 | 数值用衬线数字；涨跌同时有 ▲▼ 与文字 |
| `FactorList` | 因子条目，可展开要点 | 用原生 `<details>`，键盘可用 |
| `FactorTables` | 四类影响因素逐因子表 | 每行含覆盖画像（窗口 / 条数 / 年数 / 缺口年 / 积累期）、数据截至、发布滞后、来源 |
| `InstitutionTable` | 机构观点表 | 含预测日期与滞后标注；窄屏横向滚动 |
| `StrategyColumns` | 三档策略对照 | 窄屏堆叠为单栏 |
| `Messages` | 消息板块：24 小时 / 7 天 / 30 天三个窗口 tab，每条可展开 | 分数与排序全部来自后端确定性评分，前端不重排、不补算；原文链接新窗口打开；抓不到只显示「不可用 + 原因」 |
| `Quant` | 量化预测：见下方固定顺序 | 每个因子必须显示数据截至与来源；不可用要给原因，算不出的字段显示「—」，不填默认值 |

**量化预测页（`Quant`）的区块顺序**（自上而下，2.0.2 起）：

1. 结论行 —— 模型版本、因子可用数、数据截至与一年尺度的一句话结论；
2. **决策尺度** —— 五个尺度 tab（1 日 / 1 周 / 1 月 / 1 季 / 1 年）：方向（校准后的期望收益漂移，
   恰为 0 记「持平」）、上行概率、基准价与目标价、三情景区间与触发 / 失效条件、逐因子贡献；
   250 日方向允许 `not_published`，页面显示 `direction_reason` 的原文，**不得**画假箭头；
3. **公允价值分解** —— 市场价 vs 公允价、四块构成与驱动、拟合 R² 与样本数；
4. **监测信号（周更表）** —— 参与信号与「只看不评」分组：
   - **参与信号**：进合成得分、带方向（多 / 空 / 中性）；
   - **只看不评**：信息型指标（USDCNY、人民币金价、CFTC 未平仓、GVZ、金银比、铜金比、
     持仓比、GPR、消息强度等）只给数值与规则说明，不下方向判断。
5. **回测评估** —— 本模型与基准并排（永远看多 / 动量 / 抛硬币），CRPS 分数与技能、
   Beta 后验、分段走查（含每段的命中率、两个基准与原因）；样本不足写原因；
6. **四类影响因素** —— 逐因子表（含覆盖画像与发布滞后）。

量化页特有的口径：同步报告里的「未到期」等逐源状态收在折叠的「数据源状态」区，不占主版面；
任何一块不可用都只给原因，不摆数字；多空信号只能来自后端
`backend/app/services/quant/monitor.py` 里的确定性规则，界面不自己下判断。
情景的触发 / 失效条件必须能回到因子表与 200 日均线核对，界面不另算一套数字。
基准的可选性与滚动说明（roll / rollover note）必须原样展示，不美化。

**消息板块（`Messages`）的口径**：三个窗口各自取前 10 条，同一事件可以同时出现在多个窗口；
展开区给出摘要、评分依据（signals）、事件标注（event_tags）与同题报道链接；
经聚合入口的链接标注「经聚合入口」（`via_aggregator`）；顶部元信息展示上次抓取时间，
手动抓取后追加本次抓取报告（成功源数 / 新增条数 / 失败源数）。空窗口与空库分开：
空窗口一句说明，空库按 `StateBlock` 给出后端原因与重试路径。

## 六、界面文案

**禁用词**（界面上一律不出现）：

`Agent`、`多 Agent`、`智能驱动`、`ReAct`、`RAG`、`深度学习`、`实时抓取`（作为能力宣称），
以及 Sparkles / Bot / Brain 一类「AI 装饰」图标与 🚀✨🤖 等表情符号。

理由：当前实现是单轮 LLM 调用（见 `docs/00-产品方向.md` 第三节），这些词要么不实，要么只是装饰。
`app/e2e/dashboard.spec.ts` 会把整页文本扫一遍守住这条。

**术语表**（界面统一用词）：

| 场景 | 用词 |
|---|---|
| 分析结果的两个方向 | 看涨因素 / 看跌因素 |
| 机构目标价区块 | 机构观点 |
| 策略区块 | 投资策略 |
| 结论区块 | 今日结论 |
| 数据取不到 | 数据不可用（并说明原因） |
| 后端已开始分析 | 正在分析（并说明这是占位内容） |
| 输入不足以支撑分析 | 数据不足（说明缺什么、不生成策略，只给行情统计） |
| 分析生成时间 | 分析时间 |
| 行情来源 | 数据来源 |
| 方向停发 | 未发布（附原因，不画箭头） |
| 新序列样本尚短 | 积累期（非缺口） |
| 有缺口的年份 | 缺口年 |

**署名行**：每个分析区块底部标注
`由 {provider} {model} 生成 · 分析时间 {generated_at} · 仅供参考`；
读不到模型名时写「模型未知（/health 未返回）」，不硬编码型号。

**页脚**：数据来源一栏只列真实来源（腾讯财经、新浪财经、RSS 新闻源），
模型一栏照上面的署名行规则展示，并注明
「机构观点取每家机构最近一次可核实的预测，可能滞后（表内标注预测日期）」；免责声明保留。

**底线**：不编造数据。数据源不可用时宁可显示「数据不可用」，不得用内置常量、默认值或
模型印象生成机构目标价、央行购金量、金价点位等具体数字（见 `docs/00-产品方向.md` 第五节）。

## 七、测试选择器契约（TESTIDS）

唯一真源是 `app/src/testids.ts`，导出 `Object.freeze` 的 `TESTIDS`：

- **结构选择器**（`TESTIDS.app` / `sectionQuant` / `quantFairValue` / `researchVerdict` …）：
  给 e2e 与截图脚本定位整块区域，命名用「区块或面板」语义。
- **字段选择器**：`fieldTestId(path)` = `` `field-${path}` ``，路径用「响应类型.字段名」
  的点分命名（如 `stats.price_basis`、`quant.factors.coverage.sparse_years`、
  `accuracy.regimes.pre.accuracy`）。嵌套组件（`research`、`health`）在 `TESTIDS.field`
  里递归展开，叶子才是可直接查询的字符串。
- **组件、测试与脚本共用同一批字符串**：vitest 与 Playwright 直接 `import` 本文件；
  `app/scripts/capture_screenshots.mjs` 是 `.mjs`、不能 import TS，使用同名字面量，
  改动时必须与本文件同步（这也是本文件要求它逐块做内容检查的原因之一）。
- **字段覆盖守卫**：`app/src/sections/__tests__/fieldCoverage.test.tsx` 用全非空夹具渲染
  全部区块，逐个断言 `TESTIDS.field` 的每个叶子选择器都在 DOM 里出现。
  新增响应字段 → 先加 `TESTIDS.field` 条目 → 加展示位 → 扩充夹具，否则测试会红。
- **禁止**在测试里手写 `field-` 字符串或裸 `data-testid` 值；必须经 `TESTIDS` /
  `fieldTestId()` 引用。

**e2e 分层**：

- `app/e2e/`：默认档（`npm run test:e2e`），全程离线 —— 假 LLM + SQLite 种子库 + preview 代理；
- `app/e2e-live/`：真栈档，`E2E_LLM=real npx playwright test e2e-live` 触发；
  未设 `E2E_LLM=real` 时整组 `test.skip()`，默认跑动不受影响。真栈档断言主要区块非空、
  刷新闭环（POST `/api/gold/quant/refresh` 后内容更新且无错误态）且无不可用块。
- **截图脚本**：`node scripts/capture_screenshots.mjs` 先轮询 `/health` 的 bootstrap
  （done / disabled / skipped 或各阶段落定后才开拍），再逐块检查「非空 + 无空态标记」；
  任何一块不合格就**不写图**并以非零码退出。14 张固定文件名：
  `dashboard / price-chart / news-analysis-up / news-analysis-down / institutional-views /
  investment-advice / quant-fair-value / quant-monitor / market-summary / quant-accuracy /
  quant-prediction / research-verdict / research-forward-window / research-overview`。

## 九、动效、无障碍与打印

- 动效只用于回应人的操作（如刷新中），不做自动播放入场动画；`prefers-reduced-motion` 下全部关闭。
- 语义标签：`header` / `nav` / `main` / `footer`；每页一个 h1；skip link 直达主内容。
- 键盘焦点可见（2px ink 外框）；交互元素必须是 `<button>` / `<a>` / `<details>` 等原生元素。
- 打印：隐藏导航与操作按钮、去底色、表格与图表块内避免断页。
