## 一、需求段

### 改什么

评审列出 21 条 + 3 条次要项，覆盖五个面：信源、模型、评估、LLM 信息产品、工程治理。
本轮的验收对象就是这 24 条逐条落地或如实标注「未落地 + 原因」。按可验证性分成四批：

**R1 诚实性与正确性（代码缺陷，先修）**
1. 投资建议统计：写死的 `datetime(2025,1,1)` 改为随日历滚动的窗口；「波动区间」正名为「高低振幅」并写清定义；prompt 与口径同步。
2. `etf_shares` 未来日期：观测日不得晚于今天（存储层守卫 + 源层修复 + 测试 + 变异验证）。
3. 机构观点：news_scan 模式的总结必须由结构化行确定性拼装，禁止 LLM 总结与结构化数据互相矛盾。
4. 市场总结：机构数据缺失时禁止输出机构判断（确定性清洗 + prompt 加固）。
5. 投资建议降级语义：无因子 / 无机构 / 无新闻时不调 LLM，只给价格统计与「数据不足」说明；前端如实展示。

**R2 信源接入**
6. 消息板块 13 个高权威源接入四个 LLM 分析服务的输入包（确定性数据、不调 LLM、失败如实降级）。
7. 新闻 prompt 由「仅标题」升级为「标题 + 摘要（截断、去 HTML）」。
8. 投资建议 / 市场总结 / 多空因子的输入包统一为同一份「分析输入包」（同窗口、同价格上下文、同技能声明）。
9. LLM 输出结构校验：因子数量、去重、（best-effort）引用校验；不合格时降级而不是原样输出。

**R3 评估与数据**
10. 预测落库改为追加式每日快照（同一天同尺度一条，跨天保留）。
11. 回测新增 CRPS（连续分级概率评分），研究报告与 schema 同步展示。
12. 研究页显著标注数据窗口（样本起止 + 年数），与 README 数字口径不一致时以页面为准并说明。
13. 备份脚本（SQLite 实测；MySQL 给出明确指引）+ 测试 + 文档。

**R4 模型（研究候选，不动线上口径）**
14. `quant_lab` 新增 M 族候选：多因子直接建模（walk-forward Ridge），与「先合成再一元回归」对照。
15. M 族候选接入研究页候选说明与预注册流程（不改变线上 `quant-v6`）。

**次要项**
16. 「因子偏向（未校准）」从主表折叠进详情说明。
17. 同步报告的「未到期」噪音从用户界面挪到折叠的数据源状态区。
18. LLM 端点合规守卫：检测 `tp-` key + token-plan 端点组合时警告并给出切换指引（不改 key 本身，key 由持有人更换）。

### 判据（每条一条可红测试或可跑命令）

- R1 每条都有单元测试；改坏实现必须变红（逐条做变异验证）。
- R2：构造含 digest 条目的假输入，断言四个服务的 prompt 包含高权威条目；断言摘要截断与 HTML 清理。
- R3：CRPS 在「完美预测 / 均匀预测」构造下有已知序关系；快照策略每日可追加、同日幂等；备份脚本对临时 SQLite 全量复制并校验行数。
- R4：M 族候选在假面板上产出与基线不同的分数，且不使用未来数据（走查守卫）。
- 全绿：`backend` pytest、`app` lint+test+build。
- 文档：README 中英、ARCHITECTURE、00-产品方向、CHANGELOG 同步。

### 明确不做

- 不更换 LLM 供应商或伪造 key（合规守卫只警告；换 key 是持有人的账户动作）。
- 不接入未经实测的外部信源（WGC / IMF / CBOE 等留待下轮，先在本文件列清单）。
- 不更换线上量化模型（M 族只进研究台；换模型仍走预注册）。
- 不删除数据（历史行只修正语义，不物理删除）。

### 怎么回滚

- 每个 commit 独立 `git revert`；数据层 guard 只影响写入，不回改历史行。
- 备份脚本是新增文件，删除即回滚。

## 二、方案段

1. **R1**：`investment_advice_service` 的窗口参数化（`_fetch_window_data(start,end)`），市场总结与机构服务的清洗函数独立成模块级可测函数（`sanitize_*`）。存储守卫放在 `storage.upsert_series` 入口（`obs_date > today` 记录警告并丢弃该点，不 raise——一次坏点不能沉掉整批）。
2. **R2**：新增 `services/analysis_input.py`：`build_analysis_input(db)` 返回 `{news_block, news_items, prices_block, institutions, as_of}`；`news_digest.load_recent_entries()` 提供高权威条目（标题+摘要+来源+时间+链接），与 `gold_news` 合并去重（URL 规范化复用 `news_service.normalize_url`）。四个服务改为消费同一入口。
3. **R3**：`engine.build_prediction_frame` 增 `crps` 列（经验分布 CRPS，数值积分）；`backtest` 汇总 `mean_crps` 与基准对照；`_store_prediction` 去重键改为 `(版本, 尺度, as_of)`；`scripts/backup_db.py` 用 SQLite backup API / mysqldump。
4. **R4**：`services/quant/multivariate.py`：walk-forward Ridge（只用已实现样本对，标准化在一元扩展窗口内），`quant_lab.py` 增 M1/M2 候选；研究页候选表同步。
5. **次要项**：前端 `Quant.tsx` 折叠；合规守卫进 `llm_provider` 初始化路径 + 测试。
