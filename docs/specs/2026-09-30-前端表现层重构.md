## 一、需求段

### 改什么

把前端（`app/`）从「暗色 + 金色渐变 + 玻璃卡片 + Agent 徽章」的生成式模板观感，重构为一份
浅色财经研究简报；同时把与技术实现不符的能力宣称从界面上清除。四件事：

1. **视觉语言**：浅色纸面、排版与表格驱动；去掉渐变、发光、玻璃拟态、彩色徽章与入场动画。
2. **信息架构**：七个等权重的长滚动区块，重组为「行情 → 多空对照 → 机构观点 → 投资策略 → 总结」
   五节，锚点与导航同步更新；**内容一项不丢**。
3. **文案**：删除「多 Agent 协作」「ReAct」「RAG」「智能驱动」「实时抓取」等与实现不符的宣称
   （`docs/00-产品方向.md` 第三节已明确这些属于目标，不是现状），改为如实、平实的中文；
   保留模型名、分析时间、数据来源等可验证信息。
4. **顺带修掉的真实缺陷**：
   - 页脚把「今天」当作数据更新时间（与数据实际时间无关，且由浏览器本地时间推算）；
   - 首屏滚动指示条压住「波动区间」数据卡；
   - 图表末点闪烁光点，以及 `animate-ping/pulse/bounce/shimmer/float` 等无意义动效。

### 为什么

- 现有界面把「AI」当装饰语言（紫蓝渐变徽章、Sparkles/Bot/Brain 图标、发光卡片、金色渐变文字），
  这正是生成式页面最常见的模板痕迹，与「面向个人投资者的专业市场分析」这一产品定位不符。
- 更严重的是它把**未实现的能力**写成了既有能力：`docs/00-产品方向.md` 第三节与 `README.md` 的
  「实现说明」都写明当前是**单轮 LLM 调用** —— 没有多 Agent、没有 ReAct、没有 RAG、没有实时抓取。
  界面上的这些宣称等于替系统编造能力，违反本项目「不许编造」的红线。
- 可用性也受损：重复居中的节标题让长页面失去层级；「实时」靠一个闪烁绿点表达，颜色之外没有第二种信号。

### 怎么算做完（判据）

- **一条会红的测试**：端到端新增守卫「全页可见文本不匹配 `/Agent|ReAct|RAG|多智能体|智能驱动/i`」；
  把任一按钮文案改回「调用Agent重新分析」时它必须变红（变异验证记录见文末）。
- **一条能跑证明的命令**：`cd app && npm run build && npm run lint && npm test && npm run test:e2e`
  全绿（e2e 需要本机 Python 与 Chrome，见 `README.md`「常用命令」）。
- **页面自检**：1440×900 与 390×844 两档截图无重叠、无横向溢出；首屏不再含渐变、发光、玻璃拟态与
  彩色 Agent 徽章；「数据不可用」「正在分析」等状态文案仍然如实。

### 明确不做什么

- 不改后端、数据库、API 契约与数据层行为：`GoldDataContext`、`services/api.ts`、`useAiConfig`、
  `lib/apiError`、`lib/placeholder` 的对外行为不变（10 秒轮询、缓存、错误翻译、占位判定照旧）。
- 不换框架、不新增运行时依赖、不下载 webfont、不新增图片资产（报头用文字字标）。
- 不做暗色模式、不做多页/路由、不重做 README 的远程截图。
- 不新增功能（不加导出、不加图表缩放、不加用户偏好设置）。

### 怎么回滚

- 回滚：逆序 `git revert`，或 `git reset --hard 154e51a` 回到本轮起点。
- 前端是纯静态产物，无数据迁移、无 schema 变更、无外部配置变更，回滚不触碰任何持久化数据。

## 二、方案段

### 设计语言（冻结）

完整规范见 `docs/20-前端设计规范.md`。要点：

- 基础色：`--paper #F6F6F3`（页底）/ `--surface #FFFFFF`（表格与面板底）/ `--ink #17191B`（标题与正文）/
  `--ink-muted #5C6166`（次要信息）/ `--rule #D9DAD4`（1px 分隔线）/ `--gold #8A6A12`（金价与关键数字的
  唯一强调色，白底对比度 ≈5.1:1）；语义色 `--up #B4232A`（红涨）、`--down #16653C`（绿跌）。
- 无渐变、无阴影、无模糊；圆角 ≤2px；层次只用细线与留白。
- 字体全走系统栈：标题与数字 `Georgia, "Songti SC", "Noto Serif CJK SC", SimSun, serif`；
  正文与 UI `-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", Arial, sans-serif`；
  数字统一 `tabular-nums`。零下载、零新增资产。
- 版式：报头 + 五节，全部左对齐，最大宽 1180px；唯一的「用力处」是报头的当日报价块。
- 列宽与行宽：正文 ≤68ch，行高 1.75；字号 12/13/15/17/20/26/34。

### 结构

```
app/src/
├── styles/tokens.css       设计令牌（色/字/间距/线宽）+ reduced-motion + print
├── index.css               Tailwind 指令 + 排版基础 + 组件样式（@layer base / components）
├── components/             Section / StateBlock / RefreshButton / Quote /
│                           FactorList / InstitutionTable / StrategyColumns /
│                           PlaceholderNotice（保留语义、重绘）
├── layout/Masthead.tsx     报头：字标、锚点导航、数据来源与数据时间
├── layout/Footer.tsx       数据来源、模型说明、免责声明
├── sections/Market.tsx     行情（报价 + 走势图 + 关键数据）
├── sections/Factors.tsx    多空对照（看涨/看跌两栏，各自独立取数与刷新）
├── sections/Institutions.tsx
├── sections/Strategy.tsx
├── sections/Conclusion.tsx
└── lib/format.ts           金额/百分比/时间显示的统一格式
```

删除：`App.css`、`hooks/use-mobile.ts`（死代码）、被替换的 7 个旧 section 文件。
`components/ui/tabs.tsx` 保留（Radix 无障碍），但重绘为纸面标签页。

### 数据流

不变。各区块继续经现有 API 客户端取数；加载 / 占位 / 不可用三态判定沿用 `lib/placeholder.ts` 与
`lib/apiError.ts`；本轮只改呈现层。

### 时间与数字

- 页面上任何日期与时间**只展示后端返回的字段**（`stats.updated_at`、`last_updated`、
  `metadata.generated_at`、`dollarRealtime.date` 等），不新增 `new Date()` 推算「今天」——
  这是项目红线，理由见 `docs/ARCHITECTURE.md` 第七节。拿不到后端时间就不显示，不猜。
- 金额统一 `$4,702.20`；百分比 `+0.62% / −0.18%`；全部 `tabular-nums`、右对齐。

### 图表

保留 recharts。去掉闪烁末点与发光；金价线用 `--gold`、美元指数线用 `--ink-muted`；网格改 `--rule`
虚线；提示卡改纸面样式；保留「走势」与「美元指数对照」两个视图。

### 动效与无障碍

- 动效只保留「刷新中」的按钮态；删除 IntersectionObserver 入场动画与 pulse/ping/bounce/shimmer/float。
- skip link、`header/nav/main/footer` 语义、每节一个 h2、面板 h3、`focus-visible` 2px ink 外框、
  状态区 `role="status"`；`prefers-reduced-motion` 下关闭过渡。
- 打印样式：隐藏导航与刷新按钮、去底色、块内避免断页 —— 研究简报应当可打印。

### 测试

- 单测迁移/新增：`Market`（原 Hero 的实时/历史/不可用/来源断言）、`Factors`（原看涨四类断言 +
  看跌对等用例）、`Institutions`、`Strategy`、`Conclusion`（各覆盖有内容/正在分析/不可用/
  不得出现内置编造内容）、`lib/format`。数据层测试不动。
- e2e 更新：首屏（h1、五个导航链接、两条报价可见、无 `pageerror`）、刷新链路
  （`bullish-factors` 内点击「重新分析」→ 假 LLM 结果出现）、去 AI 化守卫。
