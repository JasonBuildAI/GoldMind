# README 截图重构与 2.0.3 发布

> 状态标记：**本轮记录**（2026-10-03）。本文只记录这一轮的需求与做法；落地后唯一权威
> 来源回到 `README.md`（截图与版本）与 `CHANGELOG.md`（2.0.3 改了什么）。

## 一、需求段（做什么、为什么、怎么算做完）

### 背景与问题

1. **截图落后于前端。** `docs/images/screenshots/` 里的 14 张图拍于前端重写之前（旧 React
   版式，侧栏没有「消息」入口与今日速览），页面上的信息架构已经变成
   「左栏（速览 + 新鲜度）→ 今日结论 → 行情 → 驱动 → 消息 → 量化 → 策略 → 数据与方法」。
2. **版式不整齐。** 现有截图用一串 `<p align="center">` 堆叠，图片宽度 400 / 620 / 800 混用、
   说明时有时无，Gitee / GitHub 上观感杂乱。
3. **缺一屏。** 「消息」已升为一等板块，但 README 里没有它的截图。
4. **截图里有碎图。** 机构观点表的 `logo` 字段其实是机构缩写（后端口径：「机构缩写，如 GS」），
   前端却按 `<img :src="GS">` 渲染 —— 浏览器把它当相对路径请求，每一格挂一个碎图图标，
   在 README 截图里肉眼可见。

### 做什么

1. 用**当前前端 + 真实栈**重拍系统展示截图；旧 `price-chart`（5434px 高的长图）拆成
   「行情」+「走势」两屏，`market-summary` 并入首屏（整页裁切，含左栏速览、数据新鲜度与
   今日结论），新增「消息」一屏（14 → 15 张）；机构缩写按字标渲染（修上一条的碎图），
   并补一条守卫测试。
2. `README.md` 与 `README_EN.md` 的截图一节改成**总览表 + 分组卡片表**（每张图一行、图下配
   说明），顺序与页面的阅读顺序一致，图片宽度统一。
3. 发布 **2.0.3**：两语言 CHANGELOG 把 `[Unreleased]` 提为 `[2.0.3] - 2026-10-03`，
   README 徽章 / 横幅 / 发布说明、后端版本号、前端 `package.json` / lockfile 同步；
   打 tag `v2.0.3`、建 GitHub Release，并把 `main` 推上去。

### 判据（会红的那种）

- `node app/scripts/capture_screenshots.mjs` 全绿：每一块都通过「有实质内容 + 无空态标记」
  的检查，任何一块退化成「暂无 / 加载中」就非零退出、不写图。
- 新增守卫 `backend/tests/unit/test_readme_screenshots.py`：README 两语言引用的每张截图都
  真实存在、都出现在**表格行**里，且「README 引用集合 == 脚本 `SHOTS` == 目录文件」三方
  一致，导语里的张数一起守；变异验证做过（改张数 / 把图移出表格 / 删一行都会红）。
- 闸门全过（pytest + compileall + gen_api_doc --check + npm lint / test / build）。

### 不做什么

- 除机构缩写这一处渲染修复外，不改前端功能代码；不重排 README 截图层以外的章节
  （版本横幅与 2.0.3 说明除外）；不新增除截图以外的二进制。

### 怎么回滚

- 全部改动在普通 commit 里，`git revert` 即可；截图由脚本 + 真实栈可重建（脚本与图片
  在同一 commit，回滚后仍自洽）。tag 与 Release 可单独删除。

## 二、方案段（怎么做）

1. **截图脚本**：新增 `messages` 一屏（`#messages`，顶部裁切，含窗口 tab 与前几条真实消息）；
   `dashboard` 改为整页裁切（左栏速览 + 数据新鲜度 + 今日结论，`market-summary` 并入其中、
   不再单独出图）；`price-chart` 那张长图拆成 `market`（报价卡 + 全字段表开头）与
   `price-trend`（先展开折叠层再单拍走势图）；为 `dashboard` 增加附加断言（侧栏必须含
   「今日速览 / 数据新鲜度 / 日期」）。另加 `SCREENSHOT_ONLY` 与 `padToText` 按秒重试
   （动机与行为见 `CHANGELOG.md` 的 `[2.0.3]`）。
2. **拍摄与目检**：真实栈（后端 8000 + 前端 5173）跑脚本；15 张逐张目检，确认无空态、
   无截断、无布局错位后写进 README。
3. **README**：`## 📸 系统展示` 改为「导语 + 15 张一览表（9 组，带张数列与合计行）+
   每张一个卡片表（① 首屏 · 今日结论 / ② 行情 / ③ 走势 / ④ 多空对照 / ⑤ 机构观点 /
   ⑥ 消息 / ⑦ 量化预测 / ⑧ 投资策略 / ⑨ 研究页）」；诚实说明（不编造、12/14 因子等）
   收进卡片说明；中英文同构。
4. **发布**：`CHANGELOG.md` / `CHANGELOG_EN.md` 提版；`backend/app/main.py`（FastAPI
   version、`/`、`/health` 三处）与 `app/package.json` + `package-lock.json` 版本号同步；
   README 两语言的徽章、发布横幅、`🆕 2.0.3 带来了什么` 对比表更新；最后
   `git tag v2.0.3` + `gh release create`。
