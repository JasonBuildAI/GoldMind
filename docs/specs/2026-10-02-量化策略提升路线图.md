## 一、需求段

### 改什么

用户的目标是**增强对国际金价的预测能力**。2026-10-02 的实测表明：当前模型在 5 个尺度上
都没有跑赢「永远看多」，而且这个结论本身还不可信 —— 评估所依赖的数据有整段缺口。因此本轮
先修数据与评估的地基，再按预注册的硬规则决定模型是否换代，最后把结论同步到文档与研究页。

1. **修数据缺口**：`real_yield_10y` / `inflation_expectation` / `policy_expectation` 在
   2018–2025 年整段缺失（实测年份分布 `2016=249, 2017=1, 2026=188`）。根因是增量抓取只请
   求首尾两个年份，中间缺口永远补不上。
2. **新增覆盖守卫**：任何因子在首末观测之间出现「样本数低于该因子年样本中位数 20% 的年份」
   必须让测试变红，防止同类缺口再次静默发生。
3. **评估口径重建**：新增 `stats.py`（分块自助置信区间、Newey–West HAC 标准误、基于 HAC 的
   Diebold–Mariano 检验、Brier 技能分、可靠性分桶、有效样本量 n/h）；回测指标对齐「开发期 /
   留出期（`HOLDOUT_START = 2023-10-02` 起）/ 全样本」三列，方向命中率必须带置信区间与
   「对基准的检验」，不再只报一个点估计。
4. **分布校准**：80% 名义区间的实际覆盖率漂移严重（最近 500 样本：70.2/66.0/64.4/55.0/27.6%）。
   把「正态分位 × 静态经验因子」换成**非对称经验分位 + 在线自适应（ACI）**，覆盖率向 80% 靠拢。
5. **新序列只入库、先不入模型**：^GVZ、SI=F（金银比）、HG=F（铜金比）、CFTC 净头寸占未平仓
   比例、GPR 官方地缘指数。它们先进库积累覆盖，等阶段 2 的预注册规则决定是否进因子集。
6. **研究台**：`scripts/quant_lab.py`（一次加载数据 → 候选 × 尺度 × 指标 → markdown + CSV，
   默认打印全部尝试）。它是阶段 2 预注册实验的执行工具，也是研究页的数据来源。
7. **模型换代按预注册硬规则决定**：候选与规则先写进本文档，之后不得修改；不满足就保留
   `quant-v4` 并如实标注「无统计优势」。长尺度（250 日）主输出改为公允价值偏离 + 校准区间。
8. **文档同步**：README 中英双版、`docs/ARCHITECTURE.md`、`docs/00-产品方向.md`、CHANGELOG、
   `docs/API.md`（由生成器产出）同步到落地结论。**文档路径只保留 SQLite 一条**（不用 MySQL、
   Docker 作为复现前提），保证别人在自己电脑上能跑起来。

### 为什么（2026-10-02 实测证据）

| 尺度 | 本模型命中率 | 永远看多 | 未校准得分方向 | 80% 覆盖率（最近 500） |
|---|---|---|---|---|
| 1 日 | 53.9% | 54.3% | — | 70.2% |
| 1 周 | 56.7% | 57.2% | — | 66.0% |
| 1 月 | 55.8% | 57.5% | — | 64.4% |
| 1 季 | 64.5% | 66.3% | — | 55.0% |
| 1 年 | 74.7% | 82.1% | 52.2% | 27.6% |

- 五个尺度全部未跑赢基准；250 日的未校准得分方向仅 52.2%，接近抛硬币。
- 覆盖率全线低于 80%：区间这个「长尺度主要输出」目前不可信。
- 而以上数字建立在**有缺口的数据**上（2018–2025 的实际利率缺失），数字本身也必须重算。
- `etf_shares` 与 `geopolitical` 各只有 1 条观测，等于没有。

### 怎么算做完（判据）

- **会红的测试**（每条都要做变异验证：改坏必须红）：
  - `tests/unit/quant/test_sync_year_range.py` —— 把 `sync.py` 的年份选择改回「首尾两年」必须红
    （构造 2016→2026 已有一段历史的库，断言请求的年份覆盖全部缺口年）。
  - `tests/unit/quant/test_factor_coverage.py` —— 人为制造一个「缺口年」必须红。
  - `tests/unit/quant/test_stats.py` —— HAC 标准误与朴素标准误在自相关序列上必须不同；
    分块自助的区间必须覆盖真实均值；DM 检验在「无差异」构造下不显著、在「有差异」构造下显著。
  - `tests/unit/quant/test_calibration.py` —— 去掉 ACI 更新必须红（构造覆盖率先高后低的漂移）。
  - `tests/unit/quant/test_no_lookahead.py` 保持全绿（垃圾值守卫不许被新代码绕过）。
- **能跑证明的命令**：`cd backend && python -m pytest` 全绿；`python scripts/quant_lab.py`
  产出开发期/留出期两列报告；回填后 `real_yield_10y` 等序列 2016–2026 每年都有观测。
- **阶段 2 的入选判据（预注册，写死不得事后修改）**：某候选在留出期上
  ① 命中率 95% 自助下界高于「永远看多」，**或** ② 命中率不劣化（≤1pp）且 Brier 技能分显著为
  正、覆盖率更接近 80%；且结论在 ≥3/5 尺度成立，或在其目标尺度成立且其它尺度不恶化（≤2pp）。
  不满足 → 保留 `quant-v4`，页面与文档如实标注「无统计优势」。

### 明确不做什么

- 不做深度学习、不做实盘交易、不做用户系统。
- 不做自动权重学习（沿用既有理由：10 年日频学自由权重必过拟合）。
- 不引入需要密钥或付费的数据源；FRED 仍为可选加速通道，不可达时回退财政部 CSV 并如实标注。
- 不重写已推送的 git 历史；不发版、不打 tag。
- 新序列本轮**不入模型**，只入库；「入库」不等于「采用」。

### 怎么回滚

- 代码：`git revert` 本轮的 commit（sync / stats / 引擎 / 脚本一起回退）。
- 数据：回填只做 insert/update，不删既有行；按 `model_version` 区分的评估历史保留。
- 校准：ACI 参数是常数量级，回滚代码即回到 v4 的静态因子。

## 二、方案段

### 1. 数据缺口的修复（`app/services/quant/sync.py` + `storage.py`）

- `storage` 新增 `year_counts(db, key)`（一次查询返回 `{年: 观测数}`）与
  `sparse_years(db, key, ratio=0.2)`（相对年样本中位数判定「稀疏年」，样本不足 2 个年份时视为全部稀疏）。
- `sync._years_to_fetch(db, key, today, history_years, max_years=3)`：
  窗口 = `today.year - history_years … today.year`；优先补窗口内的稀疏年（新的年份优先，单轮 ≤3 年，
  避免一次同步超时）；没有缺口时只刷新「最近一次观测所在年 + 今年」。treasury 源改用它。
- `yahoo` 源按已有时长决定 period：历史跨度 < 90% 请求年数时用 `"{history_years}y"`，
  否则用 `"3mo"` —— 回填与增量共用一条路径。
- `scripts/backfill_quant.py`：`--dry-run` 打印每个序列的年份覆盖与缺口；`--apply` 循环调用
  `run_sync(force=True)`（带 `--rounds` 上限与 `--years` 窗口），每轮打印新增行数，直到无缺口或
  达到轮次上限。幂等：重复运行不产生重复行（沿用 `upsert_series`）。

### 2. 覆盖守卫（`tests/unit/quant/test_factor_coverage.py`）

- 对每个 factor key：取首末观测之间的所有年份，逐年年样本数 `< 0.2 × 年样本中位数` 即判缺口，
  断言无缺口、且每个因子至少有 2 个年份有数据（否则视为「覆盖不足」单列报告而不是失败 ——
  新序列如 GPR 允许处于积累期，但必须标注）。

### 3. 统计工具（`app/services/quant/stats.py`）

```
block_bootstrap_ci(x, stat, *, block=20, n=2000, alpha=0.05, seed=…)   分块自助（保留自相关）
newey_west_se(x, lags=…)                                              HAC 标准误
diebold_mariano(loss_a, loss_b, lags=…)                               基于 HAC 的 DM 检验（双尾 p）
brier_skill_score(p, y, base_rate)                                    1 - BS/BS_ref
reliability_bins(p, y, bins=10)                                       (预测均值, 实际频率, 样本数)
effective_sample_size(n, h)                                           n/h（重叠样本的保守折算）
```

### 4. 回测指标（`backtest.py` + `definitions.py`）

- `definitions.HOLDOUT_START = date(2023, 10, 2)`（唯一一处）。
- 每个尺度的指标新增：`accuracy_ci95`、`p_value_vs_up`、`p_value_vs_momentum`、
  `effective_sample_size`、`brier_skill_score`、`reliability_bins`、`coverage_ci95`；
  输出「开发期 / 留出期 / 全样本」三列（`segments`），页面与 API 消费同一结构。

### 5. 分布校准（`engine.py`）

- 把 σ 的静态经验因子换成**非对称经验分位**：下界 `q(α/2)`、上界 `q(1−α/2)`，
  都用扩展窗口、无前视；再叠一层 **ACI**（自适应保形推断）：`α_t` 按近期覆盖误差做
  学习率 γ=0.01 的在线更新，半衰期约 250 个观测。`HorizonSpec` 增加 `headline` 字段，
  250 日主输出改为「公允价值偏离 + 校准区间」。
- 验收：250 日最近 500 样本覆盖率 ≥70%，且 1/5/20/60 日相对现状下降 ≤3pp。

### 6. 研究台与研究页

- `scripts/quant_lab.py`：加载一次数据 → 遍历候选（基线族 / 漂移三档 / 合成四档 / 分布四档 /
  因子集四档 / 集成一档）× 尺度 → 输出 markdown + CSV（默认打印全部尝试，含失败）。
- `GET /api/gold/quant/research` + `app/research.html` + `src/research/`（Vite 多页、内联 SVG）：
  技能总览、可靠性分桶、覆盖率、分段成绩、子模型与因子拆解、版本对比，附一条由数据生成的
  诚实结论。`scripts/gen_api_doc.py` 同步（否则文档闸门红）。

### 7. 依赖与数据源

- 新增 `xlrd`（GPR `.xls`）与统计相关依赖（statsmodels 可选：若安装则用，否则内置实现），
  写进 `requirements.txt` 并固定版本。
- GPR：`https://www.matteoiacoviello.com/gpr_files/data_gpr_daily_recent.xls`（实测可达）。
- 新增 Yahoo 代码：`^GVZ`、`SI=F`、`HG=F`。CFTC 占未平仓比由 `cftc_net / cftc_oi` 派生。
