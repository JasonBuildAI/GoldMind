# 量化策略提升路线图 —— 任务清单（plan）

> 与 `2026-10-02-量化策略提升路线图.md` 配套。任务 → 文件 → 测试点 → commit 边界。
> 顺序即依赖顺序；每个 commit 独立全绿。

## 阶段 1：量化地基（不动模型主干）

1. **sync 年份缺口修复** —— `backend/app/services/quant/storage.py`（`year_counts` / `sparse_years`）、
   `backend/app/services/quant/sync.py`（`_years_to_fetch`，treasury 源接入；yahoo 跨度判断）。
   测试：`tests/unit/quant/test_sync_year_range.py`（2016→2026 历史下请求年份覆盖全部缺口年；
   无缺口时只刷新最近年+今年；单轮 ≤3 年）。变异：改回首尾两年必须红。
   commit：`fix: stop skipping gap years when syncing treasury curves`
2. **覆盖守卫** —— `tests/unit/quant/test_factor_coverage.py`（稀疏年判定 + 每因子 ≥2 年的软检查）。
   变异：手工把某年样本数删到低于阈值必须红。commit：`test: guard factor series against whole-year gaps`
3. **回填脚本** —— `backend/scripts/backfill_quant.py`（`--dry-run` / `--apply` / `--years` / `--rounds`）。
   测试：`tests/unit/quant/test_backfill_script.py`（幂等：跑两遍第二轮新增 = 0；dry-run 不写库）。
   commit：`feat: add a quant backfill script with dry-run and idempotent apply`
4. **回填真实数据（20 年）** —— 本机执行 `backfill_quant.py --apply --years 20`（各源按可得起点）。
   产出：覆盖报告（写进 `docs/specs/2026-10-02-回填报告.md`）。不新增代码 → 单独 commit：
   `chore: backfill 20 years of quant factor history`
5. **统计工具** —— `backend/app/services/quant/stats.py`；测试 `tests/unit/quant/test_stats.py`
   （HAC ≠ 朴素、分块自助覆盖均值、DM 有/无差异、Brier 技能、可靠性分桶、有效样本量）。
   commit：`feat: add statistical toolkit for honest backtest metrics`
6. **回测指标三列 + 留出期** —— `definitions.HOLDOUT_START`、`backtest.py` 指标扩展；
   测试扩充 `tests/unit/quant/test_backtest_metrics.py`。commit：
   `feat: report holdout metrics with confidence intervals and skill scores`
7. **分布校准（非对称经验分位 + ACI）** —— `engine.py`；测试 `tests/unit/quant/test_calibration.py`；
   真实数据回归：覆盖率向 80% 靠拢（报告进 spec 附加段）。
   commit：`feat: calibrate prediction intervals with adaptive conformal inference`
8. **研究台** —— `backend/scripts/quant_lab.py`；测试 `tests/unit/quant/test_quant_lab.py`（候选枚举齐全、
   报告含开发/留出两列）。commit：`feat: add a quant research bench for pre-registered candidates`
9. **修复后基线重跑** —— 用研究台跑全档回测，把数字写进 spec「修复后」段（不新增代码）。
