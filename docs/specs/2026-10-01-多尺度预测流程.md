## 一、需求段

### 改什么

把 v1 的「14 因子 → 一个得分 → 1/5/20 日预测」升级为方法论要求的**多尺度四层预测流程**：

1. **多时间尺度**：预测周期扩为 1 / 5 / 20 / 60 / 250 个交易日（日内～一周 / 一月 / 三月 / 一年），
   每个尺度有各自的**主控层与权重**（短尺度看资金流、技术面、仓位；中尺度看政策预期、美元、实际利率；
   长尺度看央行购金与需求结构）。页面按尺度分页展示，防止「用长逻辑做短线」。
2. **公允价与四层分解**：用走查式回归给出「当前应该值多少」（公允价）与市场价对它的偏离度，
   并把价格拆成四块：宏观锚（实际利率 + 美元）＋ 需求结构（央行购金）＋ 风险溢价（VIX）＋ 情绪残差；
   残差走阔本身就是「有非利率因素在定价」的信号（2022 年后脱钩的量化表达）。
3. **情景输出而非单点**：每个尺度给出 Base / Bull / Bear 三情景（固定 50% / 25% / 25% 概率，
   区间由预测分布的分位数定义）、每情景的触发条件与**失效条件**；点位必须带失效条件。
4. **监测仪表盘**：方法论第七节的周更表落成 `GET /api/gold/quant/monitor`：
   每行一个指标（频率、来源、当前值、看涨/看跌信号、数据截至时间），能取的取真实数据，
   取不到的如实标「不可用 + 原因」。新增真实数据源：美元兑人民币（CNY=X，换算人民币金价参考）、
   美国财政部每日报表的 TGA 余额、纽约联储逆回购（RRP）、CFTC 未平仓合约。
5. **准确率升级**：回测覆盖全部 5 个尺度；新增区间覆盖率（80% 名义区间的实际覆盖率）
   与 2022 年前后分段成绩 —— 把「2022 年后定价函数变了」变成可核对的分段数字，而不是一句话。

### 为什么

- v1 已把数据管道与走查回测跑通，但实测命中率低于「永远看多」基线：1 日 48.99% vs 54.20%、
  20 日 53.11% vs 57.38%（2026-10-01 实跑）。根因之一是**尺度混淆**：同一套权重打所有周期，
  短周期被宏观慢变量稀释，长周期被资金流噪音污染。
- 方法论的四个尺度、四层驱动、八步 SOP、六个陷阱，需要一个**逐条对得上**的实现，
  否则「准确度升级」只能停留在口号。
- 情景 + 失效条件让预测可被证伪与跟踪（触发条件出现就改情景），
  比「给一个点位」诚实，也比「只给方向」可用。

### 怎么算做完（判据）

- **会红的测试**：
  - `tests/unit/quant/test_horizons.py` —— 同一因子面板在 1 日与 250 日尺度下权重不同、
    合成得分不同；把 `horizon_weights` 改成全尺度同权重必须变红。
  - `tests/unit/quant/test_no_lookahead.py` 扩展 —— 把 t 之后的数据改成垃圾值，
    5 个尺度的预测、公允价与分解必须逐位不变。
  - `tests/unit/quant/test_scenarios.py` —— 三情景的区间必须来自预测分布分位数
    （改坏 σ 必须变红）；数据不足时返回不可用而不是编数字。
  - `tests/unit/quant/test_monitor.py` —— 每行指标要么有真实值与信号、要么有不可用原因；
    信号翻转规则用构造数据逐行钉住。
- **能跑证明的命令**：`cd backend && python -m pytest`、
  `cd app && npm run build && npm run lint && npm test` 全绿；
  真实数据刷新后 `/api/gold/quant/predictions` 返回 5 个尺度（含情景与公允价），
  `/api/gold/quant/monitor` 返回 ≥10 行且每行状态可解释，`/api/gold/quant/accuracy` 返回 5 个尺度的评估。
- **页面自检**：5 个尺度分页可切换；每个尺度显示情景与失效条件；仪表盘不可用行显示原因。

### 明确不做什么

- 不做实盘交易、不下单、不接券商（沿用 `docs/00-产品方向.md` 第五节）。
- 不引入付费或需要注册密钥的数据源。
- 不做自动权重学习：10 年日频样本学自由权重必然过拟合；权重先验由方法论的分层表给出，
  由逐尺度回测接受检验，先验与实测都摆在页面上。
- 不做 3～10 年货币体系信用层的量化（去美元化、财政可持续性无免费高频量），
  只用央行购金与长尺度代理；不冒充已有能力。
- 不用 CME FedWatch / FOMC 点阵图原始数据：政策预期沿用「2Y 收益率 − EFFR」自算代理并标注。
- SGE 上海金溢价：公开无密钥接口实测不可用（返回空），仪表盘行如实显示不可用，不编数。

### 怎么回滚

- 代码：逆序 `git revert` 本轮的 commit。
- 数据：本轮**不改表结构**，只往 `factor_observations` 追加新序列（usdcny / cny_gold / tga / rrp / cftc_oi）；
  回滚停用 `QUANT_ENABLED` 即可，历史数据不动。

## 二、方案段

### 尺度与权重（唯一真源仍在 `backend/app/services/quant/definitions.py`）

| 尺度 | 交易日 | 主控层（方法论第一步） |
|---|---|---|
| 日内～一周 | 1 / 5 | 资金流、技术面、仓位拥挤度 |
| 一～三个月 | 20 / 60 | 政策预期、经济数据、美元指数 |
| 半年～一年 | 250 | 实际利率周期、降息路径、央行购金 |

每个因子在 `FactorDefinition` 上带 `horizon_weights`（缺省回落到基础权重）；
合成得分 `score_h = Σ w_i(h)·signed_z_i / Σ w_i(h)`。权重数字是方法论分层表的设计先验，
写在一处、逐行注释，回测按尺度检验。`MODEL_VERSION` 升为 `quant-v2`，v1 的历史评估原样保留。

### 公允价与四层分解（新模块 `decompose.py`）

- 走查式扩展窗口 OLS：`log(金价) ~ 实际利率 + log(美元指数) + log(央行储备) + VIX`，
  t 时刻的系数只用 `s ≤ t−1` 的样本拟合（无前视）。
- 输出（单位同时给美元与占比）：
  - **中枢**：需求与避险处于样本均值、实际利率与美元取当前值时的模型价；
  - **需求溢价** = 中枢 × (exp(β_cb·(x_cb − x̄_cb)) − 1)；
  - **风险溢价** = （中枢 + 需求溢价）× (exp(β_vix·(x_vix − x̄_vix)) − 1)（链式相乘，保证恒等式精确）；
  - **情绪残差** = 市场价 − 中枢 − 两个溢价（残差占比越大，说明模型外因素在定价）。
  - **公允价** = 中枢 + 需求溢价 + 风险溢价；**偏离度** = 市场价 / 公允价 − 1；报告拟合 R² 与样本数。
- 四块之和恒等于市场价（按定义构造），有单元测试钉住。

### 情景（新模块 `scenarios.py`）

- 由该尺度预测分布 `N(μ, σ²)`（μ = 期望收益，σ = 不确定度）的分位数定义：
  Base = [q25, q75]（50%）、Bull = q75 以上（25%）、Bear = q25 以下（25%）；
  价格区间由分位数换算，无上/下界如实用「以上 / 以下」表达。
- 触发条件与失效条件由当前面板数据生成（取该尺度权重最大的可用因子 + 200 日均线），
  每个数字都可以在因子表里核对；金价序列或分布不可用时返回不可用 + 原因。

### 监测仪表盘（新模块 `monitor.py`，`GET /api/gold/quant/monitor`）

方法论第七节模板逐行落地：10Y TIPS、盈亏平衡通胀、DXY、政策预期（代理）、央行净购金、
黄金 ETF 份额、CFTC 净多头（拥挤度规则）、上海金溢价（不可用+原因）、VIX、信用代理（HYG/IEF）、
200 日均线；另加人民币金价参考（美元金价 × USDCNY）、TGA、RRP、COMEX 未平仓量。
每行：`{key, name, frequency, source, value, unit, change, obs_date, signal, signal_label, note}`；
`signal ∈ {bull, bear, neutral, null}`，`null` 表示信息型指标（如汇率、未平仓量），不硬加多空。

### 数据源新增（全部免费、无需密钥）

| 序列 | 来源 | 频率 | 处理 |
|---|---|---|---|
| usdcny | Yahoo（CNY=X） | 日 | 当日收盘 |
| cny_gold | 金价 × USDCNY ÷ 31.1035 | 日 | 元/克参考价 |
| tga | 美国财政部 Fiscal Data（每日报表 TGA 期末余额） | 日 | 百万美元 |
| rrp | 纽约联储逆回购结果 API（按日汇总） | 日 | 亿美元 |
| cftc_oi | CFTC 同报告新增解析 `open_interest_all` | 周 | 张 |

### 准确率指标

- 每个尺度回测：命中率 + 三基准（永远看多 / 动量 / 抛硬币）+ Brier + **80% 区间覆盖率**；
- `metrics.regimes`：以 2022-01-01 为界分段报告命中率与样本数（对齐「2022 年后脱钩」的认知）；
- 逐因子 IC / 命中率沿用；新尺度上的缺失因子照旧如实标注。

### 接口

- 改：`GET /api/gold/quant/predictions` —— 5 个尺度；每个尺度新增 `range_low/high`、`scenarios`、
  尺度标签；顶层新增 `fair_value`（公允价、偏离度、四块分解）。
- 增：`GET /api/gold/quant/monitor` —— 监测仪表盘。
- 其余（factors / accuracy / refresh）不变，随新尺度与指标自动扩展。

### 降级

- 单个新源失败：对应仪表盘行 `signal=null` + 原因；其余行照常。
- 情景或公允价算不出：各自返回不可用 + 原因，不阻塞预测主输出。
