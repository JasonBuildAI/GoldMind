# 2026-10-03 2.0.2：20 条整改、自动化与前端重写（spec）

> 上游：第三轮评审的 20 条评估（用户提供）+ 用户三项要求：全部自动化、前端重写、真实 LLM 验收后发版。
> 状态：**进行中**。落地结论以 `README.md` / `docs/` 为准，本文件只是这一轮的记录。

## 一、需求段

### 改什么

1. **落地 20 条改进中高价值且可自主完成的部分**：金价口径标注、源可用性对账、事件标注、
   评分权重敏感性、sentiment 死字段清理、方向 KPI 换口径、250 日停发方向、Regime 候选、
   因子覆盖标注、发布滞后建模（quant-v7）、基准对照候选、双库一致性、前向裁决 Beta 后验、
   消息强度序列、LLM 产物去复述、数据新鲜度、调用门控与预算、刷新鉴权。
2. **全自动化**：`backend/.env` 是唯一人工输入。启动引导自动建表、自动迁移、自动回填、
   自动首轮分析；LLM 配置热生效；调度自愈；自动备份与体检。人工脚本降级为可选运维工具。
3. **前端重写**：更清晰的层级与结构，所有 API 字段都有展示位，保留无障碍/打印/窄屏规则。
4. **真实 LLM 验收**：假 LLM 套件进 CI；真实 LLM 端到端链路本地执行留证；真实栈重拍
   14 张截图且逐块检查非空。
5. **发布 2.0.2**：版本号四处一致、CHANGELOG 中英、tag 与推送。

### 为什么

- 方向命中率与「永远看多」逐日一致、Brier 技能分为负、250 日覆盖 28.8% —— 现有输出没有
  可证明的信息优势，必须先修数据可见性（发布滞后）、再修评估口径（增量 KPI、Beta 后验），
  并停止发布统计上不可区分的方向。
- 人工步骤（init_db / backfill / migrate / 手动刷新）是系统可用的隐性前提，与「配置即用」
  的目标冲突；把它们全部收进启动引导与调度层。
- 前端信息密度高但层级混乱，低价值内容与关键结论同权展示，需要「结论先行 + 一层展开」。

### 怎么算做完（判据）

- 每条落地项：代码 + 测试或可复跑命令 + 文档；外部源不可达的项在 spec 记「未落地 + 原因」。
- 自动化：**零人工冷启动**验收 —— 空目录 + 只配 `.env`，启动后不执行任何命令，
  在限定时间内库表齐备、历史回填完成、七节 + 研究页均有内容；重启一次验证幂等。
- 前端：字段覆盖测试证明每个响应字段都有展示位；E2E 选择器常量表固定。
- 全档闸门全绿：`python -m pytest`、`compileall`、`gen_api_doc --check`、
  `npm run lint` / `test` / `build` / `test:e2e`。
- 发版：版本号四处一致；tag `v2.0.2`；CI 三个 job 全绿。

### 明确不做

- 不采购付费数据；无免费/合规依据的源不硬接，如实记未落地。
- 不改用户 `.env` 里的密钥（不可逆，须用户账户侧操作）。
- MySQL 自动备份不代跑 mysqldump（如实标注）。
- 不为了「好看」重排生产因子权重；评分权重敏感性只报告，不改线上口径。

### 回滚

- 每个改动单位独立 commit，revert 即回退。
- 数据类操作先备份（`scripts/backup_db.py`）；自动迁移只做加列/建表，不删除数据；
  迁移前 SQLite 自动备份到 `backend/backups/`。
- quant-v7 换版后：旧 `quant-v6` 记录保留在库中，带版本号可查；前向窗口按新封板日重启，
  理由写入预注册文档。

## 二、方案段

### 1. 量化（quant-v7）

- `definitions.py`：`FactorDefinition` 新增 `publication_lag_days`（工作日）；
  国债收益率类因子（`real_yield_10y` / `inflation_expectation` / `policy_expectation`）
  设 1 —— H.15 在当日收盘后、EFFR 在次日发布；CFTC/央行储备保持 0（源层已按可用日打标）。
  引擎按「观测日 + lag 个工作日」作为可见时点对齐，展示层的年龄计算同一口径。
- `MODEL_VERSION = quant-v7`；`ACTIVE_HOLDOUT_START = 2026-10-03`（重新封板，v6 注单作废）。
- 250 日尺度输出 `direction_status = not_published` + 原因；方向置空，保留公允价值偏离与区间。
- 回测指标新增：`direction_edge_vs_always_long`（带置信区间）与「敢喊跌质量」
  （喊跌次数 / 命中 / 相对基准），研究页与 README 一级展示。
- 前向裁决新增 Beta 后验（先验 `Beta(1,1)`，写死并注释）与 CRPS 并排；入选规则不动。
- 研究台新增 Regime 候选（实际利率周期 / 美元周期 / 央行购金时代）与基准对照候选
  （GC=F / XAUUSD=X / 展期口径），只进研究台，过预注册闸门才谈上线。
- 新派生序列「高权威消息强度」（消息板块评分加权计数），同表存储 + 监测行，预注册候选。

### 2. 全自动化

- `app/bootstrap.py`：迁移注册表（`schema_migrations` 表）+ 覆盖度检测 + 分阶段任务；
  挂在 FastAPI lifespan，幂等、可中断续跑；`/health` 暴露进度。
- 迁移：quant 三表、institution 列、digest URL、枚举列修正全部转为自动迁移。
- 回填：价格/美元历史、新闻与消息首抓、量化因子全历史（`QUANT_BACKFILL_YEARS=20`）、
  修订流水；失败下轮重试，缺口如实报告。
- 首轮分析：数据就绪后自动触发五个 LLM 分析（受指纹门控与每日预算约束）。
- 热生效：`.env` mtime 监听，LLM 相关字段变化时重载并立即补一轮；其余项在 /health 提示。
- 调度：启动补差 + `coalesce` + `misfire_grace_time`；每日自动备份（保留 7 份）与数据体检。

### 3. 信源与接口

- 抓取尝试流水 + `GET /api/gold/sources/status`；实时金价与最新收盘的偏差检查。
- 事件标注（确定性规则）注入消息展示与 prompt；聚合入口来源显式标注。
- 价格响应附 `basis` / 来源 / as-of；新闻响应移除 `sentiment` 并删除情感端点（破坏性）。
- 可选 `REFRESH_TOKEN` 保护 POST refresh；`LLM_DAILY_CALL_BUDGET` 默认 200。

### 4. 前端

- 结构：报头（速览 + 新鲜度）→ 今日结论 → 行情 → 驱动 → 量化 → 策略 → 数据与方法 → 页脚；
  每节「一句话结论 + 关键数字 + 一层 details」。
- 字段覆盖：以 `app/src/services/api.ts` 类型为清单的渲染测试；设计规范维护字段映射表。
- E2E 与截图脚本同步重写选择器；14 张截图真实栈重拍。

### 5. 测试与发版

- 后端全档 + 变异验证；前端 lint/test/build + Playwright（假 LLM）；
  `E2E_LLM=real` 真实链路验收 + `smoke_llm.py` + 真实栈截图。
- 文档同步：README 中英、CHANGELOG 中英、产品方向、ARCHITECTURE、API、设计规范、密钥文档。
- 版本 2.0.2：`app/package.json`、`main.py` ×3；tag `v2.0.2`；推送 main 与 tag。
## 三、第四轮预注册（2026-10-03 写死，之后不得增删）

动机（第三轮评审第 10、13 条）：线上模型只在一个方向上挖增量，从未回答「这套信号在
什么状态下才适用」以及「换一把基准尺子结论会不会变」。两条都必须是**先写死、再执行**的
对照实验，而不是看到成绩之后再挑口径。

口径实现唯一真源：`app/services/quant/regimes.py`（窗口、状态定义、基准清单）；
执行：`scripts/quant_lab.py`（`--group regime` / `--group benchmark`）；
对齐守卫：`tests/unit/quant/test_quant_lab.py` 把本表与代码逐项对齐。

| 组 | 数量 | 候选（key：口径） |
|---|---|---|
| Regime 三档 | 3 | R1 实际利率周期（10 年期实际利率低于其 504 个交易日滚动中位数时持仓）/ R2 美元周期（美元指数低于其 504 个交易日滚动中位数时持仓）/ R3 央行购金时代（中国官方黄金储备的 252 个交易日变化为正时持仓） |
| 基准对照两档 | 2 | G1 基准 = GC=F 期货收盘（控制，与生产同基准，含展期）/ G2 基准 = GLD 收盘（ETF、无展期影响；对照组是同基准的 G1） |

- **Regime 口径**：状态不成立时记中性 0 分（不反向）；滚动窗口最少观测 252 个
  （不满 1 年不产生状态）；只用当日及以前的数据。
- **判据沿用**：阶段 2 入选判据（`preregistered` 规则与 `docs/specs/2026-10-02-量化策略提升路线图.md`
  §6.1 上方那段）一字不改，不新增阈值；三样本期（开发 / 历史留出 / 前向）全部报告。
- **不进生产**：两组只进研究台；在前向窗口过线之前，一律不加进线上信号或基准。
- **不可达记录（未落地 + 原因）**：XAUUSD 现货基准 —— Yahoo 图接口 2026-10-03 实测 404；
  展期调整后的连续序列 —— 需要逐月合约与展期价差，无免费合规来源，本轮不构造。
