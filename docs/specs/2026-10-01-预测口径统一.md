## 一、需求段

### 改什么

一个尺度的预测只有一个真源：走查校准后的 h 日收益率分布 `N(μ, σ²)`。

1. **方向 = sign(μ)**。μ = α + β·score 是扩展窗口 OLS 用**已实现样本**（`s + h ≤ t`）
   拟合出来的期望收益；现在页面上的「方向」取的是**未校准的合成得分符号**，
   两者会互相打架。
2. **上行概率 = Φ(μ / σ)**。现在取的是 `Φ(score / σ_score)`，与目标价无关：同一个面板上
   可以同时出现「看跌」「上行概率 22%」「目标价高于基准价」三套说法。
3. **σ 改为走查预测误差的标准差**。现在是回归残差 σ（拟合线周围的散布），
   它把「模型自己错多少」漏掉了：实测 80% 名义区间在 20 / 60 / 250 日的实际覆盖率
   只有 69.7% / 63.9% / 47.2%，不确定性被系统性低估。
4. **回测评的就是页面上的那个方向**。命中率、Brier 分、区间覆盖率、2022 分段
   全部改用同一列 μ / σ；未校准的得分方向另立一列 `metrics.score_direction_accuracy`
   继续报出来，不藏、不混。
5. **模型版本升为 `quant-v4`**（v3 统一分布；v4 在 σ 上追加经验分位宽度校准，
   见文末落地补记）；`quant-v1` / `quant-v2` / `quant-v3` 的历史评估原样保留。

### 为什么（2026-10-01 真实数据实测）

| 周期 | 页面方向（得分符号） | 校准后的期望收益方向 | 永远看多 | 80% 区间实际覆盖率 |
|---|---|---|---|---|
| 1 日 | 49.4% | 53.0% | 54.2% | 78.3% |
| 1 周 | 50.0% | 55.9% | 57.2% | 76.0% |
| 1 月 | 53.8% | 54.4% | 57.4% | 69.7% |
| 1 季 | 47.9% | 61.9% | 66.2% | 63.9% |
| 1 年 | 53.5% | 65.3% | 77.0% | 47.2% |

- 60 日的得分方向 47.9% 是**反的**：该尺度 β 的走查值近 1000 日里只有 41% 为正、均值≈0，
  也就是说这个尺度上得分没有可用信息，而校准后的 μ 会自动退回到漂移项（61.9%）。
- 页面在自我否定：方向说看跌、目标价却高于基准价、上行概率又是另一个方向的口径。
  对一份「可核对」的研究简报来说，这是比数字低更严重的问题。
- 覆盖率低于名义值说明区间太窄，会让「区间」这个最主要的输出失去参考价值。

### 怎么算做完（判据）

- **会红的测试**：
  - `tests/unit/quant/test_engine.py::test_direction_follows_the_calibrated_expectation` ——
    把方向改回得分符号必须变红（同一份面板需要构造出「得分为正、期望收益为负」的时刻）。
  - `tests/unit/quant/test_engine.py::test_probability_up_comes_from_the_same_distribution` ——
    把 p_up 改回 `Φ(score/σ_score)` 必须变红。
  - `tests/unit/quant/test_engine.py::test_uncertainty_is_the_walk_forward_error_not_the_fit_residual` ——
    把 σ 改回回归残差必须变红（构造「拟合很准但预测误差很大」的数据）。
  - `tests/unit/quant/test_engine.py::test_uncertainty_is_calibrated_to_the_empirical_error_quantile` ——
    去掉经验分位校准必须变红（后段波动换挡，校准前近端覆盖明显低于名义值）。
  - `tests/unit/quant/test_backtest_metrics.py::test_accuracy_scores_the_calibrated_direction` ——
    把回测方向改回得分符号必须变红。
  - `tests/unit/quant/test_no_lookahead.py` 全部 5 个尺度继续绿。
- **能跑证明的命令**：`cd backend && python -m pytest`、`cd app && npm run build && npm run lint && npm test`
  全绿；真实数据刷新后 `/api/gold/quant/predictions` 里「方向」与「目标价相对基准价的方向」
  一致、`/api/gold/quant/accuracy` 里 5 个尺度的 80% 覆盖率向 80% 靠拢。

### 明确不做什么

- 不做自动权重学习（沿用上一轮 spec 的理由：10 年日频学自由权重必过拟合）。
- 不改表结构、不改数据源、不加新接口。
- 不删除历史评估：`quant-v1` / `quant-v2` 的行保留用于对照。
- 不为「命中率好看」丢基准：永远看多 / 动量 / 抛硬币三档继续并排展示。

### 怎么回滚

- 代码：`git revert` 本轮的 commit（引擎、回测、前端文案一起回退）。
- 数据：预测与评估历史按 `model_version` 区分，回滚后新版本行仍留在库里，不删。

## 二、方案段

### 唯一的预测定义（`app/services/quant/engine.py`）

```
score_t          = Σ w_i(h)·signed_z_i / Σ w_i(h)            因子偏向（未校准，仅展示与单列回测）
μ_t(h)           = α̂_t + β̂_t · score_t                      扩展窗口 OLS，样本对 (score_{s−h}, r_s) 且 s ≤ t
e_t(h)           = r_t − μ_t                                 预测误差（t 时刻已知的只有 s + h ≤ t 的 e）
σ_t(h)           = std({e_s : s + h ≤ t}) × q80(|e|/(z80·σ))  走查误差标准差 × 经验分位校准；样本 < 60 时退回已实现收益的扩展标准差
p_up             = Φ(μ / σ)                                  与目标价、区间、情景同一个分布
方向              = sign(μ)（恰为 0 记 flat）
目标价            = 基准价 × (1 + μ)；80% 区间 = μ ± 1.2816σ
```

- `e` 用 `(forward − expected).shift(h)` 对齐：t 行取到的误差在 t 时刻**已经实现**，
  与 `test_no_lookahead.py` 的垃圾值守卫兼容。
- σ 用同一分布的预测误差而不是回归残差：残差只说明「拟合线周围的散布」，
  预测误差才是「模型自己错了多少」。

### 回测（`backtest.py`）

- `direction = np.sign(frame["expected_return"])`（与页面同一个 μ）；
  被评估样本的筛选条件不变（score / 已实现收益非空、可用因子 ≥ 3、收益非 0）。
- 新增 `metrics.score_direction_accuracy`：未校准得分符号的命中率，与旧口径可比。
- Brier 与区间覆盖率自动跟随新的 `probability_up` / `uncertainty`（同一 frame）。

### 出口与界面

- `MODEL_VERSION = quant-v4`（`definitions.py`）。
- 页面「回测命中率」口径表新增一行「因子偏向（未校准）」，与「本模型」并排 ——
  两个数字都摆出来，读者自己判断校准有没有价值。
- 页面文案：方向 = 「模型对 h 日后价格的方向（漂移 + 因子，走查校准）」；
  因子表保留「方向信号 z」，但不再自称方向。

### 落地补记：区间宽度的经验分位校准（2026-10-01）

统一分布落地后实测：80% 名义区间在近 500 个可评估样本的覆盖率只剩
70.0% / 64.0% / 58.8% / 47.6% / 18.4%（1 日 → 1 年）—— 正态分位（1.2816σ）在
误差非正态 / 波动换挡时系统性偏窄。补一步 **expanding 经验分位校准**（无前视）：

- `build_prediction_frame`：σ 之后追加 `factor = q80(|e|/(z80·σ))`，`σ ← σ × factor`；
  滚动窗口实测更差，不用。`backtest.INTERVAL_Z_80` 改为引用 `engine` 的唯一口径。
- 实测（同日）：全样本覆盖率 51.8% → 61.0%（250 日）、68.4% → 76.7%（60 日）；
  近 500 样本 18.4% → 27.6%（250 日）、47.6% → 55.0%（60 日）。
- 残留：250 日近两年仍低（走查误差平均 +33.0%，μ 低估 2024–2025 年上涨）。
  试过按误差扩展均值校正 μ（近 500 覆盖 27.6% → 41.6%），但 1–60 日命中率一律下降
  （60 日 64.5% → 60.5%），未采用；如实展示，不修饰。
