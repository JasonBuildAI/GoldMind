## 结论

- 本轮「数据缺口修复」的目标序列（`real_yield_10y`、`inflation_expectation`、
  `policy_expectation`）已从「2018–2025 整段缺失」变为 2006–2026 每年都有观测。
- 剩余稀疏年是**源本身的可得范围**造成的（BTC 起点、RRP 设立时间、新闻语料
  上线时间、快照式序列），不是抓取逻辑跳过；`tests/unit/quant/test_factor_coverage.py`
  会区分「缺口」与「积累期」。
- 回填可重复执行：重复运行只做 upsert —— 第二次运行新增 0 行（测试
  `test_backfill_script.py::test_apply_fills_history_and_repeat_run_is_idempotent`）。

## 复现方式

```bash
cd backend
python scripts/backfill_quant.py --dry-run --years 20   # 先看覆盖与缺口
python scripts/backfill_quant.py --apply  --years 20 --rounds 10
```

`--apply` 需要联网访问各数据源；不可用时如实记入同步报告，不编造数据。
