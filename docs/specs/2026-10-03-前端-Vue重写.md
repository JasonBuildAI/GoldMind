## 一、需求段

### 改什么

把前端（`app/`）整体重写。四件事：

1. **可读性与结构化**：现在的 `app/src` 把「区块」「通用组件」「量化子件」平铺在一起，
   单个文件最大 42 kB（`research/ResearchPage.tsx`），一个文件里塞进多个面板；
   层与层之间没有边界。重写后按**功能**分组，每个文件只讲一件事。
2. **内容一项不丢**：所有响应字段都必须在页面上有展示位（当前是 210 个字段级选择器），
   所有区块、所有口径说明、所有「不可用 + 原因」都要在。
3. **视觉语言换成 macOS 观感**：分层表面、发丝线、圆角、极轻阴影、半透明工具条、
   系统字体与系统色板。现行规范里「无阴影、无圆角（0–2px）、无模糊」这条硬约束作废。
4. **换掉技术栈**：React → Vue 3；顺带删掉**实际没用上**的 Tailwind（全库 639 处
   `className` 里只有 6 处是工具类）与 recharts（只用在 2 处图表，换成自绘 SVG）。

### 为什么

- 界面是给人读的：区块挤在一起、层级靠卡片和字号混着表达，读者找不到「结论在哪」。
  这一条在本轮以「按功能分组的目录 + 每节先给一行结论」的方式解决。
- 现行视觉语言（纸面、衬线标题、零圆角、零阴影）与产品定位（现代金融工具）之间
  没有冲突，但也谈不上好用：表格与面板之间没有层次，长页面读起来累。
- 换 Vue 是本轮**有意**的技术栈决策（用户指定）：Vue 单文件组件把模板、逻辑与样式收在
  一个文件里，配合「按功能分组」的目录，结构比现在清晰；同时能把 React 生态里
  没用上的依赖（Tailwind、recharts、lucide、radix）一并清掉。
- 这次重写**不改产品行为**：轮询节拍、缓存、重试、错误翻译、文案、口径说明全部照旧。

### 怎么算做完（判据）

- **一条会红的测试**：字段覆盖守卫（`app/src/views/dashboard/__tests__/fieldCoverage.test.ts`）
  用全非空夹具挂载全部区块，逐个断言 210 个字段级选择器都在 DOM 里；
  删掉任一字段的展示位必须变红。
- **一条会红的测试（新）**：去 AI 词守卫渲染全部区块后扫描可见文本，
  不匹配 `/Agent|ReAct|RAG|多智能体|智能驱动/i`；把按钮文案改回「调用Agent重新分析」必须变红。
- **一条能跑证明的命令**：`cd app && npm run lint && npm test && npm run build && npm run test:e2e`
  全绿；另跑 `cd backend && python -m pytest`（后端有三条守卫会读前端源码）。
- **页面自检**：真实栈下 1440×900 与 390×844 两档无横向溢出、无重叠；
  `node scripts/capture_screenshots.mjs` 能重拍 14 张图（逐块检查「有实质内容 + 无空态标记」）。

### 明确不做什么

- 不改后端、数据库、API 契约与响应字段；不新增接口。
- 不改产品行为：30 秒轮询、隐藏暂停、5 秒缓存、429 退避、付费语义不重试、
  错误翻译、全部界面文案与口径说明照旧。
- 不加暗色模式、不加客户端路由、不加导出、不加图表缩放、不加用户偏好设置。
- 不下载 webfont（系统字体栈）；不新增图片资产。
- 不重做 README 引用的**远程**截图；本轮只在本地重拍同样的 14 个文件名。

### 怎么回滚

- 前端是纯静态产物：无数据迁移、无 schema 变更、无外部配置变更。
- 单 commit 原子替换，`git revert <sha>` 即回到 React 版本；`dist/` 与部署配置无需改动。

## 二、方案段

### 技术栈（版本钉死，理由写在这里）

| 包 | 版本 | 为什么是它 |
|---|---|---|
| `vue` | `3.5.43` | npm 的 `latest` 标签当前指向 `3.6.0-rc.10`（RC），显式钉稳定版 |
| `pinia` | `4.0.3` | 行情 / 新鲜度 / AI 配置三个共享状态；`peerDependencies.vue: ^3.5.11` |
| `@vitejs/plugin-vue` | `6.0.9` | 与 `vite@7` 兼容（peer `^5 \|\| ^6 \|\| ^7 \|\| ^8`） |
| `@vue/test-utils` | `2.5.1` | 组件测试；替代 `@testing-library/react` |
| `vue-tsc` | `3.3.12` | `npm run build` 的类型检查改用 `vue-tsc -b` |

**不引入 `vue-router`**：`vue-router@5.3.1` 的 peer 里要求 `vite ^7.3.0`、`pinia` 与
`@pinia/colada`，为了两个静态页引入它不划算。保留 Vite 双入口
（`index.html` + `research.html`）—— 相对链接 `./research.html` 已在 nginx 与 e2e 里用着。

**删掉的依赖**：`react` / `react-dom` / `@types/react*` / `@vitejs/plugin-react` /
`@testing-library/react` / `@testing-library/user-event` / `@radix-ui/react-tabs` /
`recharts` / `lucide-react` / `clsx` / `tailwind-merge` / `tailwindcss` / `postcss` /
`autoprefixer` / `eslint-plugin-react-hooks` / `eslint-plugin-react-refresh`。
**删掉的文件**：`tailwind.config.js`、`postcss.config.js`、`components.json`。

### 冻结的接口（重写不许碰）

这三处不是「顺手也能改」的，后端测试直接读它们：

| 冻结项 | 谁在依赖 |
|---|---|
| `app/src/testids.ts` 的路径、导出名与全部字符串（210 个字段级 + 57 个结构选择器） | 前端组件、vitest、Playwright、`scripts/capture_screenshots.mjs` |
| `app/src/services/api.ts` 的路径，以及其中 `/api/gold/...` 字面量与 `params.append('start_date', ...)` 的写法 | `backend/tests/unit/test_api_params_contract.py:223` 硬编码读这个文件；同文件按正则解析查询参数 |
| `package.json` 里的 `npm run lint` / `npm test` / `npm run build` / `npm run test:e2e` 名字 | `backend/tests/unit/test_docs_reference_real_paths.py` 校验 README 里的 npm 命令真实存在 |

另：`backend/tests/unit/test_env_example_completeness.py` 用 `rglob("*.ts*")` 收集
`import.meta.env.VITE_*`，`VITE_API_URL` 留在 `api.ts` 即继续被扫到。

### 设计语言（macOS/HIG）

令牌定义在 `app/src/styles/tokens.css`，规则写进 `docs/20-前端设计规范.md`。要点：

- **分层表面**：窗口底 `--bg` / 内容面 `--surface` / 次级面 `--surface-2`，
  左栏用 `--sidebar-bg`，用发丝线 `--separator` 分隔，而不是靠卡片堆叠。
- **版式**：两栏壳 `.app-shell` = 左栏（`--sidebar-width` 300px，整列吸顶）+ 内容区
  （`minmax(0, 1fr)`，吃掉剩余宽度）。**整页铺满，不再把正文居中收窄**；可读性靠各区块
  自己的 68ch 行宽上限。窄于 `--bp-narrow`（960px）落成单栏。
- **几何**：圆角 6（按钮）/ 8（卡片）/ 10（左栏内的分组）；阴影只有两级 `--shadow-1`（卡片）
  与 `--shadow-2`（浮层），同级不混用。
- **字体**：全走系统栈 `-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", …`，
  删掉衬线栈；标题与正文同族，靠字重 / 字号 / 字距分层。数字统一 `tabular-nums`。
- **色**：Apple 语义色（`--accent #0071E3`、`--text #1D1D1F`、`--text-secondary #6E6E73`…），
  涨跌沿用红涨绿跌（`--up` / `--down`），金价用 `--gold`。所有前景/背景对按 4.5:1 实测，
  不达标就调深。
- **左栏与浮层**：`backdrop-filter: saturate(180%) blur(20px)`，`@supports not` 时退回不透明面。
- **仍然禁止**：装饰性渐变、发光、玻璃拟态堆叠、彩色徽章、AI 装饰图标与 🚀✨🤖 类表情。
- **语义不靠颜色**：涨跌必须同时有 ▲▼ 与「涨/跌」文字。
- **动效只响应人的操作**：150ms 色/阴影、220ms 展开；`prefers-reduced-motion` 全关；
  不做自动入场动画。

### 行为契约（逐条照旧）

1. 行情 30 秒轮询，页面隐藏暂停，切回立即补一次；5 秒缓存窗口；同 URL 在飞去重。
2. 429 尊重 `Retry-After`；网络 / 408 / 425 / 429 / 5xx 退避重试 ≤2 次带抖动；
   **含 `refresh=true` 的 GET 与所有 POST 不重试**（付费语义）。
3. 时间只展示后端字段，不用 `new Date()` 推算「今天」；拿不到就写「时间未知」。
4. 不可用一律「不可用 + 原因」，不填默认值；`direction_status: not_published`
   只显示 `direction_reason` 原文，不画箭头。
5. 所有细节折叠最多一层，不嵌套两层。
6. 界面文案与术语表照旧（`今日速览`、`数据新鲜度`、`重新分析`、`展开逐条因子`、
   `未发布`、`积累期`、`缺口年`、`数据不足`…）—— e2e 与截图脚本直接断言这些字符串。

### 顺带被守卫抓到的真实缺陷

写 `pageStructure.test.ts` 时它立刻报出 `存在重复 id: ['tab-1','tab-5','tab-20',…]` ——
量化预测的「决策尺度」与「回测评估」两组 tab 共用 `tabpanel-${horizon}` 作为面板 id，
同一页面上 5 个 id 各出现两次，`aria-controls` / `aria-labelledby` 会指向错误的元素。
修法：`TabsNav` 要求调用方给 `panelId` 前缀，两组分别传 `quant-scale` 与 `quant-accuracy`。
这不是守卫的假阳性，是它在第一天就抓到的问题。

### 同一轮的口头追加：版式改成两栏

重写落地后用户提出「改成左右排版、整页铺满」。这属于「重写版式」而不是另一件事（需求段
第 1 条就是「可读性与结构化」），因此**并进同一个 commit**，并把判据补进本轮：

- 左栏 `AppSidebar`：字标、锚点导航、今日速览、数据新鲜度；整列吸顶。
- 内容区 `.app-main` 吃掉剩余宽度；去掉居中收窄的 1180px 版心，改由各区块 68ch 行宽兜底。
- 窄于 960px 落成单栏；左栏回到页面顶部横条。
- 新增 `app/scripts/verify_layout.mjs`：真浏览器里实测两档视口无横向溢出、两栏铺满、
  左栏吸顶与发丝线、令牌生效、无装饰性渐变/发光、锚点可达、对比度 ≥ 4.5:1。

**这次自检抓到了三个真实的排版缺陷**（单元测试在 happy-dom 里看不见，因为它没有排版引擎）：

| 症状 | 根因 |
|---|---|
| 390px 视口下文档宽 1025px | 栅格 / 弹性容器的子项缺 `min-width: 0`，长段落与表格把轨道顶宽 |
| 表格所在栏被顶宽 | `.table-scroll` 自身缺 `min-width: 0`，「表内滚动」变成「整页滚动」 |
| 图表在 1440px 下也越界 40px | 没清掉浏览器给 `figure` 的默认外边距 `1em 40px` |
