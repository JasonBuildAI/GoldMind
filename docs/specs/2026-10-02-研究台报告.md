## 复现方式

研究台只读因子库、不发网络请求；17 个候选 × 5 个尺度全档约 3–5 分钟。

```bash
cd backend
python scripts/quant_lab.py --out ./quant_lab_out     # 产出 quant_lab.md / quant_lab.csv
```

本文件即该命令的原始产出（原样收录，包括无过线候选的裁决）。研究接口
`GET /api/gold/quant/research` 读的是同一套 `backtest` / `preregistered` 实现，
用 1 小时缓存挡住重复计算，不重新挑选候选。
